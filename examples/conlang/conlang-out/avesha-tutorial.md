# Learn Avesha

A first walk through Avesha — its sounds, a starter vocabulary, how words combine, and a sentence to read. Work top to bottom.

## 1. The sounds

**Consonants:** p · t · k · s · m · n · l · r

**Vowels:** a · i · u

## 2. Your first words

| Word | Pronunciation | Meaning |
|---|---|---|
| **pata** | /pa.ta/ | stone |
| **palu** | /pa.lu/ | run |
| **talu** | /ta.lu/ | river |
| **tani** | /ta.ni/ | speak |
| **kira** | /ki.ra/ | bird |
| **kanu** | /ka.nu/ | hand |
| **suna** | /su.na/ | sun |
| **nami** | /na.mi/ | see |

## 3. Putting words together

Avesha is a **SOV (subject–object–verb)** language — arrange a clause in that order.

Words inflect. Here is **pata** in its forms:

- **pata** — stone
- **patasi** — stone-DAT
- **patau** — stone-PL

## 4. A first text

> kira suna nami. tani palu.

Word by word:

```
kira       bird
suna       sun
nami       see
tani       speak
palu       run
```
