# Inkhaven 1.3.17 — The ConLang Suite (Part 4: the books) · LANG-1 complete

_1.3.14–1.3.16 built the constructed language itself — its phonology, lexicon,
morphology, diachronics, and a real compiled writing system. 1.3.17 turns that
language into **books**: a dictionary, a reference grammar, and a learner's
textbook, all as proper typeset documents. With it, **RFC LANG-1 is complete**
— from an empty `Language` book to a printed dictionary, grammar, and tutorial,
with an AI-drawn font, entirely inside inkhaven. Reference:
[CONLANG.md](../CONLANG.md). Zero new dependencies._

## The grammar book (P6.3)

- **`inkhaven language grammar-book <lang> --format md|typ`** renders a reference
  grammar from the language's own data: phonology (inventory, syllable
  structure, phonotactics, allophony, stress, tone), morphology (affixes,
  derivation), the typology answers with their consequences, idioms & metaphors,
  and the sample texts. The companion volume to the 1.3.16 dictionary.

## The learner's textbook (P7)

- **`inkhaven language tutorial <lang> --format md|typ [--provider …]`** is
  **written by the AI**: the model authors a complete graded course — a warm
  introduction, a pronunciation guide, lessons that *explain* the grammar with
  worked examples, a reading passage, and a practice exercise per lesson —
  constrained to the language's actual sounds, words, and rules (it never
  invents vocabulary or grammar). The prose is generated, never hardcoded.

## The grammar's study guide

- **`grammar-book … --study --provider …`** turns the reference into **study
  material**: an AI-written study guide leads the book, defining and explaining
  every linguistic term the grammar uses — phoneme, allophony, grammatical case,
  SOV word order, nominative–accusative alignment, agent nouns, … — grounded in
  this language's examples. The reference itself stays deterministic; only the
  study guide is AI-authored.

## A book design

- The dictionary, grammar, and tutorial now share a polished, manual-style book
  design (a B5 page, serif body, a title page, a table of contents, callout
  boxes), modelled on the Book of Inkhaven. The Typst documents embed the
  conscript font and compile to PDF with `typst compile --font-path <dir> …`.

## A complete worked example

- **`examples/conlang/build-sample-language.sh <project>`** builds a whole
  language end to end — phonology → lexicon → morphology → an **AI-drawn script**
  → an in-process TrueType font → the dictionary, grammar, and tutorial — and a
  checked-in sample of its output lives in `examples/conlang/sample-output/`.
  See also [Tutorial 74](../Tutorials/74-conlang-end-to-end.md).

## Design notes

- **AI where the value is judgement, deterministic everywhere else.** The
  dictionary and the grammar reference are rendered deterministically from the
  language's data; the tutorial and the grammar study guide — where teaching
  prose is the point — are AI-authored thin layers, constrained to the
  language's facts.
- **AI writes Markdown; we own the Typst.** The model always emits Markdown
  (which it does reliably); a deterministic Markdown→Typst converter and a fixed
  page scaffold turn that into a book that always compiles and embeds the font.
- **Reuse over new deps.** No new dependencies this release.
