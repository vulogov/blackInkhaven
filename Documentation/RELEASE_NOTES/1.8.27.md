# Inkhaven 1.8.27 — Agentic research iterates (RESRCH-6 P3)

_Agentic research stops doing one pass and starts closing its own gaps: after the initial
plan+gather, a critic proposes follow-up sub-questions for what's unanswered or contradictory,
and the loop iterates — under a bounded, transparent stop condition. **No new runtime crates.**_

## The gap-driven iterate step

`inkhaven research --agentic "<topic>"` now loops:

1. **Plan + gather** (round 1, as in 1.8.26) — decompose, research each sub-question, emit Facts.
2. **Critique** — a critic reviews the *facts established so far* (not the plan) and lists
   follow-up sub-questions for what's still **unanswered or contradictory**, or nothing when the
   topic is covered.
3. **Iterate** — gather the follow-ups, emit more Facts, critique again — until it stops.

## The stop condition (the hard part, made explicit)

The loop terminates on the first of three bounds, and the run reports which:

- **Budget spent** — the *total* sub-question budget (`research.agentic.max_subquestions`, now a
  ceiling across all rounds) is reached. Hard cost cap.
- **Round cap** — `research.agentic.max_rounds` (default 3; set `1` for a single pass) is hit.
- **Converged** — the critic proposes nothing more.

It can never loop forever (both a budget and a round cap bound it), and **dropped sub-questions
are logged in the report, never silently truncated** — with a hint to raise the budget. The
termination decision is a pure, unit-tested function.

Everything else is unchanged: Facts are emitted into the Facts book with `model` provenance at
an untrusted tier, integrated with fact-check / contradiction / `/undisputed`; gated by
`research.agentic.enabled` (on by default).

## Config

```hjson
research: {
  agentic: {
    enabled: true          // master switch (set false to disable)
    max_subquestions: 6    // TOTAL Facts budget across all rounds
    max_rounds: 3          // max iterate rounds (1 = single pass)
  }
}
```
