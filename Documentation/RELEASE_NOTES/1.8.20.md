# Inkhaven 1.8.20 — Source beside translation (POEM-TUI PO-P15)

_A two-column view for translated verse: source and translation side by side, with the
Form/Sound trilemma measured beneath them. **No new runtime crates.**_

## The paired-translation model

A `para:verse-translation` (⇄) paragraph now holds both halves of a translation in one
body, separated by a delimiter line — either the thematic `⇄`, or a rule of three-or-more
dashes (`---`) you can actually type. Source above, translation below:

```
Мой дядя самых честных правил
---
My uncle, a man of the purest honour
```

New translation paragraphs are seeded with the `---` rule so the format is obvious.

## The two-column view — `Ctrl+B J → P → T`

With a translation paragraph open, `Ctrl+B J → P` then **`T`** opens a review pane that
shows the source and the translation **side by side, line-aligned**, with the trilemma
measured underneath:

```
 source (ru)                    │ → translation (en)
 Мой дядя самых честных правил  │ → My uncle, a man of the purest honour
 ── trilemma (ru → en) ────────
 Form    ██████░░░░   62%   …
 Meaning ░░░░░░░░░░         the AI axis — engage the Inner Poet (E)
 Sound   ████████░░   80%   …
```

- The **source language is detected** (whatlang); the translation language is the project's.
- **Form** (metre + rhyme fidelity) and **Sound** (alliterative texture carried across) are
  measured by the shipped trilemma engine; **Meaning** stays blank — it is judgement, not a
  number, and the pane points you to the Inner Poet's slow track (`E`) for it.
- If the paragraph has a declared form, the trilemma checks against it. Read-only review — it
  never rewrites a line.

## Dependencies & compatibility

**No new runtime crates.** Reuses `poetry::translation` (the trilemma) and `whatlang` (already
in the tree). The source/translation splitter is factored into the engine and unit-tested.
Warning-free (binary and tests). Test suite → 2657.
