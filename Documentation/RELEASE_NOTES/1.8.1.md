# Inkhaven 1.8.1 — Readability & Universal Dependencies

_Two additions that make the linguistic layer pay off in both directions: a
quantitative **readability** pass over your own manuscript, and **CoNLL-U** export so
your glossed texts round-trip into the Universal Dependencies ecosystem. Plus a new
allophony chapter in the Linguistic companion. **No new runtime crates.**_

## Quantitative readability

`inkhaven style` — the deterministic, offline style report — now closes with a
**readability** section per book, alongside the existing filter-word / repeated-phrase
/ show-don't-tell / anachronism detectors:

- **Lexical diversity** — total tokens, distinct types, and the type–token ratio.
- **Sentence rhythm** — sentence count, mean length, the standard deviation and
  coefficient of variation of length (the *rhythm*), and the longest sentence. Prose
  whose sentences are all the same length is flagged as *monotone rhythm*.

Both are computed with Unicode-aware word and sentence segmentation, so the numbers are
meaningful for Russian, French, German — any script, not just English. Available in the
plain report and under a new `readability` key in `--json`. Zero AI, nothing is
rewritten — it measures, you decide.

## CoNLL-U export

`inkhaven language texts <lang> --format conllu` exports your stored interlinear texts
as **CoNLL-U**, the interchange format of the [Universal
Dependencies](https://universaldependencies.org/) project (joining the existing
`--format latex`). Each word becomes a token row with:

- **FORM** and **LEMMA** from the gloss,
- **UPOS / XPOS** from the lexicon's part of speech (mapped to the UD universal tags),
- **FEATS** read straight off the Leipzig gloss — a `-PL-GEN` tag becomes
  `Case=Gen|Number=Plur`, canonically ordered.

The tag→feature map is language-independent, so a Russian genitive (`дом-а`,
`house-GEN`) and an invented language's genitive export identically, ready to load
alongside UD's own treebanks. HEAD/DEPREL are left unspecified — this is a valid
morphology-only treebank; a full dependency parse is a later increment.

## Books

- **Linguistic Research with Inkhaven** gains an *allophony* section: how to declare
  ordered phonological rules (`g > k / _ #`) and derive a word's surface form with
  `language ipa` — Russian final devoicing turning underlying *друг* into surface
  *друк*, one rule predicting a whole class of words. Its glossing chapter now covers
  CoNLL-U export.
- **Developing a Constructed Language** — the interlinear-text chapter documents
  `--format conllu`.

## Dependencies & compatibility

**No new runtime crates.** The readability metrics reuse the bundled Unicode
segmentation; CoNLL-U export is a pure renderer beside the existing LaTeX one. Purely
additive — one new `--format conllu` value and a new report section, no behaviour
changes to existing commands. Warning-free (binary and tests). Test suite → 2587.
