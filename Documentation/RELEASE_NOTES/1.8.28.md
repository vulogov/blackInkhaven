# Inkhaven 1.8.28 — The agentic contradiction gate (RESRCH-6)

_Autonomous research now checks itself for contradictions — rigorously, with the same `⇄`
detection `/contradict` uses — as it emits Facts, so the loop self-corrects and the run flags
conflicts before you trust anything. **No new runtime crates.**_

## The in-loop contradiction gate

After each gather round of `inkhaven research --agentic "<topic>"`, the run scans **its own
emitted facts** for contradictions using the dedicated primitives (`gather_facts` →
`join_provenance` → `consistency_groups` → `parse_clashes`) — not the critic's eye, but the
real `⇄` detection. What that buys:

- **The critic acts on them.** Detected contradictions are handed to the next round's critic,
  which proposes follow-up sub-questions to *resolve* them (establish which side is right and
  why) — so the loop self-corrects instead of accumulating conflicting facts.
- **The run flags them.** The report gets a prominent **⚠ Contradictions** section
  (`fact-a ⇄ fact-b — reason`), and the completion line names the count. You resolve them
  before promoting the affected facts (`/contradict` re-scans).

It scans only the run's *own* facts (not the whole Facts book), so it stays bounded and
focuses on exactly what the autonomous emission introduced. This is the piece that makes
autonomous emission trustworthy: the facts land untrusted **and** their internal conflicts are
surfaced, so review is targeted.

## Why it matters

The whole risk of autonomous fact-emission is filling the Facts book with material that quietly
disagrees with itself. The gate turns that from a hidden hazard into an explicit, actionable
finding — and, because it feeds the critic, into follow-up research that tries to settle it.

## Dependencies & compatibility

**No new runtime crates.** Reuses the shipped contradiction detection end to end; the batch
research chain now returns the emitted fact's id so the gate can scan it. Warning-free (binary
and tests). Test suite → 2665.
