# Inkhaven 1.6.11 — Search & Review

_Refinements to the web-publishing release, plus a review dashboard and a rendering
fix. The published site gains real search, honours the status floor, and the
manuscript gains a readiness view. No new runtime crates._

## Site search (TDOC-4.2)

Exported websites now have **search** built in. A box at the top of the sidebar finds
any word across every page as the reader types — entirely on their own machine, with
no server, no library, and no network. The site stays **self-contained**: the search
index and script are ordinary files loaded with a `<script>` tag (not a `fetch`), so
search works even when the site is opened straight from disk.

It is on by default; turn it off with `docs: { html: { search: false } }`.

## `export html` honours `--status`

HTML export now respects the status floor like every other format: `inkhaven export
html -o site --status ready` publishes only the paragraphs you have marked ready,
leaving drafts out of the public site.

## The review dashboard (TDOC-5)

`inkhaven docs review` reports the readiness of your manuscript — a per-chapter status
breakdown and a list of every paragraph still below the floor (`--floor`, default
`ready`), exiting non-zero when any remain (a pre-release / CI check). With
`--since <git-tag>` it flags the paragraphs whose source changed since a release, so
you re-read exactly those:

```
inkhaven docs review
inkhaven docs review --floor final --since v1.5.0
```

## Fixes & docs

- **Long inline code now wraps.** A long `code` span mid-sentence used to run past the
  page margin in the companion books; inline code now breaks across lines like any
  other text.
- The *Publish Your Book to the Web* companion gains **Appendix A — Tags, subtypes,
  and status**: a plain-language reference distinguishing the status ladder
  (`Ctrl+B r`), structural subtypes (`Ctrl+B m` — code, admonitions, procedure, table,
  math), and tags (`Ctrl+B ]`, including `profile:*` editions), with how to assign each.

## Dependencies & compatibility

**No new runtime crates.** New command `inkhaven docs review`; new config
`docs.html.search` (on by default); `export html` now reads `--status`. Everything is
additive — existing projects are unaffected. Test suite → 2352.
