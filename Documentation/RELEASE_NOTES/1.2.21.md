## Highest-value candidates (new)

These surfaced during the 1.2.20 review as the biggest
gaps for a working novelist — none are carryovers, all
are feature-cycle material.

### Cross-book find-and-replace (the standout)

Today find/replace works only on the open paragraph
([Tutorial 03](../Tutorials/03-the-editor.md)); the
concordance ([Tutorial 40](../Tutorials/40-concordance.md))
is read-only.  **Renaming a character across every
chapter is the single most common structural edit a
novelist makes, and the tool can't do it.**  Perfectly
on-theme for a revision product; fits the existing
store-walk + doctor-scan + snapshot machinery for safe
bulk mutation (preview diff, snapshot every touched
paragraph before applying).

### "Publishable book" polish

Make the export an actual finished book:

* **Print front-matter** — title page, copyright /
  colophon, optional ToC for the PDF (and ePub).  The
  PDF compiles via typst but emits no title page today.
* Pairs with the now-landed ePub cover (1.2.20 R.1.b)
  into one coherent finishing theme.

### Spell-check (deferred-but-real)

A genuine absence — F7 is LLM grammar-check, there's no
dictionary spell-check.  Heavier (hunspell + per-
language dictionaries), so weigh it against the cycle's
dep budget; lower priority than the two above.

## Carryovers from 1.2.20

### D.3.b — store-side prose-walk dedup

`epub` + `audiobook` still share an `append_branch_prose`
shape (store-side) that 1.2.20's D.3 left alone because
they genuinely differ (xhtml + `<h2>` vs plain).  Low
value — only unify if a third store-side consumer
appears.

### D.7 — reading-time + sentence-split unify

`text_utils::format_reading_time` (fixed 250 wpm) vs
`tui/reading_time` (configurable); `continuity.rs` vs
`sentence_rhythm.rs` sentence boundaries.  Low value,
do only if a cycle touches these areas anyway.

### M1 / M3 — security hygiene

* M1 — crash-report action-ring `detail` length cap
  (cheap defensive bound; latent, low actual risk).
* M3 — `[script: <slug>]` prefix on script-opened
  modals (theoretical for a single-user local tool).

### R.1.b remainder — ePub polish

Cover landed.  Still open: inline images carried into
chapter XHTML, popup footnotes (`epub:type="noteref"` +
notes section) instead of the inline span, and a
`--paragraph-headings` opt-in.

## Carryovers from 1.2.19

### C.2.b — Russian + German quantity lexicons + bootstrap

* Russian + German number-word / unit / direction
  lexicons (Cyrillic declension + German compounding
  want native-speaker / LLM verification before
  bundling).
* `inkhaven bootstrap-continuity <lang>` — LLM-seed CLI
  so any language can be seeded + hand-corrected in
  HJSON.  Currently blocked on the lexicon-bundling
  verification above.

### C.3.b — embedding drift + TUI bible view

* Embedding-based synonym-aware continuity comparison
  ("green" vs "emerald" reads as consistent; cross-
  language facts match).  Needs a public
  `Store::embed(text)` accessor.
* TUI continuity-bible view — browse each character's
  extracted facts + flagged drift in a modal.

### Anachronism overlay

Flag period-inappropriate vocabulary against the
project's declared setting — needs period-vocabulary
lexicons.  Pairs naturally with a genre-packs cycle.

## Themes under consideration

### Dialogue & voice

The natural next revision-craft cycle:

* Character voice consistency (does X speak in their
  established voice here?).
* Dialogue-ratio gauge (% dialogue vs narration).
* Dialogue-tag detector (said-bookisms, adverb-laden
  tags, tag overuse).
* Per-character verbal-tic report.

### Genre packs

Mystery + historical-fiction templates + style-rule
packs (clue tracker, fair-play audit, the anachronism
overlay co-shipping).

### AI maturity

Multi-paragraph envelope (±1 paragraph), hot-reload
`prompts.hjson`, AI streaming into the editor at the
cursor.

### Finishing & submission

Query-letter + synopsis AI helpers (RAG-grounded),
front/back-matter nodes (dedication, acknowledgments,
copyright page), full-book read mode.

### Other candidates

* Sixth supported language — Italian / Portuguese /
  Japanese.
* GitHub Release object backfill for 1.2.11–1.2.19.
