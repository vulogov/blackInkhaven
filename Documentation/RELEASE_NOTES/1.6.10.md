# Inkhaven 1.6.10 — Publish to the Web

_A book you can visit. This release turns any manuscript into a self-contained HTML
website — one command, no web expertise, nothing that phones home — and ships a new
companion book that teaches it end to end. No new runtime crates._

## The HTML site exporter (TDOC-4)

`inkhaven export html -o site/` renders your book as a **self-contained static
website**: one page per chapter, a sidebar table of contents, a clean reading theme,
your images copied alongside. It opens from disk or drops onto any static host, and it
has **zero external dependencies** — no CDN, no web fonts, no scripts loaded from
elsewhere. The chrome is localised to the book's language, and TDOC-3 single-sourcing
variables and `--profile` editions apply exactly as they do for PDF.

### Templates you own — the functional / visual split

You need no templates to publish — a bare export renders a complete, styled book from
templates embedded in the binary. When you want to customise:

```
inkhaven export html --eject-templates my-design    # write the defaults out
inkhaven export html -o site --templates my-design  # export using them
```

The templates split into **`functional/`** (the page skeleton and navigation — the
machinery) and **`theme/`** (the stylesheet and visual partials — the look), so a
designer can restyle without touching a line of the plumbing. The full default set
also ships under `examples/html_templates/` for reference. Site-wide values come from
an `html.hjson` file, exposed to the [minijinja](https://docs.rs/minijinja) templates
as `site` (an HJSON → Jinja bridge).

### Publish your whole shelf — companion inclusion

`docs.html.include.*` folds your companion books into the same site as appendix pages,
integrated into one contents list:

```hjson
docs: { html: { include: {
  sources: true    glossary: true      # book back-matter (on by default)
  characters: true places: true        # cast, gazetteer
  world: true      language: true       # switch on what you've written
} } }
```

- **Sources** → a formatted, author-sorted **bibliography**.
- **The Language** → a **sortable, filterable lexicon table** — click a column to
  sort, type to filter (self-contained inline JS, no library).
- **The World** → a **narrative guide** written up from your `world.hjson`: its sky,
  lands, waters, peoples, livelihood, laws of magic, and history, in readable prose.
- **Characters / Places / Glossary / Mythology** → their entries, prose or as tidy
  cards. An empty book adds nothing; your private workshop stays off the site by
  default.

## New companion book — *Publish Your Book to the Web*

A sixth book joins the shelf (`Book/WEBSITE/`), in the same voice and design as the
others. It teaches HTML export for authors who are neither web nor Inkhaven experts:
every term defined, every command shown with an example, and full chapters on styling
(CSS), templates (Jinja), variables (HJSON), choosing what to publish, and going live.

## Dependencies & compatibility

**No new runtime crates.** New export format `html` (`export html`), new config
`docs.html`, new flags `--templates` / `--eject-templates`. The default templates ship
inside the binary (so `cargo install` needs no extra setup) and under
`examples/html_templates/`. Everything is additive — existing projects are unaffected.
Test suite → 2349.
