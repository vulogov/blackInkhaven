# Inkhaven 1.8.3 — WordNet

_A sense-based thesaurus for your prose. `inkhaven wordnet` fetches open WordNet data on
demand and looks a word up for its **senses** — each with synonyms, antonyms, and
hypernyms/hyponyms. This release lays the foundation with English; the other standard
languages and an in-editor chord follow. The data is open and fetched, never bundled._

## `inkhaven wordnet`

A writing aid, distinct from the constructed-language layer — it works on real prose,
not invented lexicons.

```sh
inkhaven wordnet fetch en        # download Open English WordNet, build the local index
inkhaven wordnet lookup light    # senses, each with its relations
inkhaven wordnet list            # sources + what's installed
```

A lookup is **sense-based**, so polysemy is handled properly — *light* returns its noun
and adjective senses separately, each with its own definition and its own antonyms
(*heavy*, *dark*):

```
light · en
  2. adjective
     of comparatively little physical weight or density
     antonyms   heavy
  3. adjective
     (used of color) having a relatively small amount of coloring agent
     synonyms   light-colored
     antonyms   dark
```

For each sense you get **synonyms** (co-members of the synset), **antonyms** (from
sense-level relations), and **hypernyms / hyponyms** (from synset-level relations).

## Fetch-on-demand, offline thereafter

The data is not bundled. `wordnet fetch` downloads the open
[WN-LMF](https://globalwordnet.github.io/schemas/) distribution, parses it, and builds a
compact index under the user data directory — after which every lookup is offline. This
release fetches **Open English WordNet 2025** (CC BY 4.0): 152,459 lemmas, 120,564
synsets. The parser keys every synset by its interlingual index (ILI), which is the hook
the other languages will link through.

## What's next

The standard languages this feature targets — **Russian, French, German, Spanish** — ship
as `.tar.xz` OMW archives and land in the next release, linked to English through the ILI.
After that, the in-editor **WordNet chord**: stand on a word, pull its senses and
relations, and replace it in place. `wordnet list` already shows the roadmap and each
source's licence.

## Dependencies & compatibility

Promotes two crates already present in the dependency tree — `bincode` (index
serialisation) and `flate2` (gunzip of the download) — to direct dependencies; no new
crates enter the build. Purely additive: one new top-level `wordnet` command, nothing
else changes. Warning-free (binary and tests). Test suite → 2602.
