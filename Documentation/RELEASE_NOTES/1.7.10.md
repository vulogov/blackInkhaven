# Inkhaven 1.7.10 — The Oracle Joins the Review Pass

_1.7.9 gave the Oracle an eye on the paragraph you just saved. This release widens
it to the whole book: the phonotactic guardian now runs in the review pass,
sweeping every chapter for malformed conlang words in one go. Zero-AI, advisory,
never editing. No new runtime crates._

## Book-wide phonotactic sweep

The on-save guardian checks the paragraph in front of you. The review pass
(`Ctrl+B J`) now runs the same scan across the entire manuscript, alongside the
other deterministic readers (fact, socrates, timeline, dialogue, utopia, character,
theologian, myth, rigor). For each defined language it loads the phonology,
morphology and lexicon once, then scans every user-book paragraph — skipping the
system books, exactly as `scan-manuscript` does — and surfaces each ill-formed
conlang word as an advisory Output finding (`⌥`):

```
⌥ [Eldar] `ktal` breaks phonotactics — contains an illegal onset cluster
```

The review-pass tally now includes an `oracle N` count. As always the check is
purely advisory — it emits findings and nothing more, and it only speaks up in
paragraphs that already contain a word of the language, so prose in your working
language is untouched.

## Dependencies & compatibility

**No new runtime crates.** Purely additive — a book-wide `run_oracle_check` joins
the unified review pass, reusing the same `oracle::scan_prose` engine and `oracle:`
config block introduced in 1.7.9; gated on `oracle.enabled`; a no-op for projects
with no languages. Existing projects, languages and prose are unchanged. The
companion book notes the review-pass sweep. Warning-free (binary and tests). Test
suite → 2549.
