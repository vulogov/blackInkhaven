# Inkhaven 1.8.35 — Unicode Covers & the Audit's Long Tail

_The last non-ASCII data bug from the pre-major audit is closed — the native PDF cover now
embeds a Unicode font — and the audit's LOW tail is swept: latent panics, overflow guards,
multilingual fixes, and a few small perf/robustness items. Each fix ships with a regression
test._

## The PDF cover renders in every language

The native (Typst-free) cover drew spine and back text as base-14 Helvetica with no encoding,
so a Cyrillic (or `café` / `Müller`) title printed as mojibake. The cover now embeds **DejaVu
Sans Mono** — bundled by `typst-assets` (TrueType with full Cyrillic + Latin coverage, and
already in the binary via the font kit, so no size cost) — as a **Type0 / CIDFontType2** font
with Identity-H encoding, reading the glyph map and metrics via `ttf-parser` and emitting a
ToUnicode map so the text stays selectable. It's monospace — this is a geometric fallback
cover, not typeset body — but correct in every project language (en/ru/fr/de/es). Falls back to
Helvetica when the font is unavailable (correct for ASCII). _The watermark text (same class) is
a follow-up._

## The audit's LOW tail

- **Latent panics & overflow guards** — every NaN-unsafe `partial_cmp().unwrap()` in the world
  compile layers now `unwrap_or(Equal)` (a `world.hjson` producing NaN can't panic the
  deterministic compile); `calc.gcd`/`lcm` are `i64::MIN`-safe; year magnitudes and a couple of
  index subtractions use `unsigned_abs` / `saturating_sub`.
- **Research** — the autonomous (`--agentic`) loop now surfaces a failed critic or
  contradiction-gate call to stderr instead of silently reporting "converged"; `/gutenberg`
  recognizes chapter headings in ru/fr/de/es (was English-only, with a byte-length cap that
  rejected Cyrillic early).
- **Smaller items** — `oracle`/`poem` output sources are now reachable in the `/` filter;
  `typst_check` measures the real CRLF line terminator; the Thoughts log is capped; and the
  background DuckDB checkpoint runs on a blocking thread.

## Dependencies & compatibility

Two new direct dependencies — `typst-assets` (features `["fonts"]`) and `ttf-parser` — both
already compiled in the tree (no new download). Compiles warning-free. Test suite → 2680.
