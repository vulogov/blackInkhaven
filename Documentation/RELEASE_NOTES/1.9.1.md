# Inkhaven 1.9.1 — Worldbuilder, Documented

_A documentation release. 1.9.0 shipped the interactive worldbuilder; 1.9.1 teaches it
properly. No code changes — every worldbuilder feature behaves exactly as it did in
1.9.0._

## Full TUI guidance in *Building the World*

The companion book *Building the World with Inkhaven* gains a rebuilt **Chapter 20,
"The Interactive Worldbuilder,"** with faithful monospace **terminal screens** — the
same approach the *Poetry* and *Research* companions use for their TUIs. Eight screens,
each rendered and checked against the running interface, walk through:

- the four-pane layout and the live plausibility score in the status bar;
- a mid-interview conversation (the Sky stage);
- the shaping-delta confirmation modal;
- `/compile` and `/validate` output;
- the ASCII biome **Map** pane;
- the **Research** pane after `/research`;
- the **Ledger** pane;
- the `/journey` session timeline.

The chapter also carries a complete key table and command reference. A new note early
in Chapter 3 points readers to the interactive builder before they reach the end, and
the book's page furniture is a `screen()` helper ported into its design system.

## Also

- Chapter 3 gains a pointer to `inkhaven worldbuilder` so the interactive path is
  discoverable from the first world you build.
- The reference docs (`WORLDBUILDING.md`, `KEYBINDING.md`) carried the full worldbuilder
  key and command tables as of 1.9.0; the book now matches them screen-for-screen.

## Compatibility

Documentation only — no dependency, behaviour, or API changes from 1.9.0. Compiles
warning-free. Test suite unchanged at 2712.
