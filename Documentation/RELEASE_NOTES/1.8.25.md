# Inkhaven 1.8.25 — Exact English scansion (the pronouncing dictionary)

_Closes the one limitation the poetry book openly documents: English metre and rhyme, read
from spelling alone, are approximate. Install a pronouncing dictionary and they become exact.
**No new runtime crates.**_

## The problem it fixes

English spelling doesn't encode sound (`cough` / `bough` / `through`), so reading scansion
from spelling has three rough spots the book flags plainly:

- syllable counts guessed by a silent-e heuristic,
- stress guessed by position (which gets "compare" wrong),
- and — most visibly — `love` / `move` reported as a **perfect** rhyme, because the spelling
  tails match, when they're a textbook *eye* rhyme.

## The fix — an optional pronouncing dictionary

```sh
inkhaven poetry phonemes import cmudict.dict   # install (CMUdict format, from CMU Sphinx)
inkhaven poetry phonemes lookup compare        # com-PARE · 2 syllables · rhyme tail /EH R/
inkhaven poetry phonemes status
```

Once installed, the scansion engines read each word's **actual phonemes** instead of its
spelling:

- **Syllables** = vowel-phoneme count (exact).
- **Stress** = the phoneme marked primary (no more penult guess).
- **Rhyme** — `love` / `move` is now correctly an **eye rhyme** ("looks alike, sounds
  different"), while a true pair like `day` / `may` stays perfect.

It's **English-only** — Russian, German, and Spanish are near-phonemic and already accurate,
so they never consult it — and **words outside the dictionary fall back to the spelling
heuristic**, so nothing breaks and the dictionary is entirely optional. It ships as a data
file you import (like the WordNet indexes), not bundled in the binary.

The pronouncing dictionary flows through everywhere the engines are used — `poetry syllabify`
/ `metre` / `rhyme` / `scan`, the Inner Poet, and the Bund `ink.poem.*` words — transparently.

## Book updated

The two honest-limitation callouts in _Poetry with Inkhaven_ (the syllable chapter and the
rhyme chapter) now describe the fix instead of calling it a "deferred improvement," and the
command reference lists `poetry phonemes`.

## Dependencies & compatibility

**No new runtime crates.** The engine public API is unchanged (`syllable_count` /
`analyse_rhyme` gained internal `*_with` variants for the optional dictionary; existing call
sites are untouched). Warning-free (binary and tests). Test suite → 2663.
