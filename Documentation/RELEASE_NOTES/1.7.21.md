# Inkhaven 1.7.21 — The Corpus Reads Your Book

_The corpus engine only knew the interlinear texts you had glossed by hand. Now it
reads the language as you actually write it: the conlang words in your manuscript
prose join the corpus, so frequency, concordance and collocation reflect real usage,
not just a handful of curated examples. No new runtime crates._

## The corpus reaches into the prose

Every corpus command now takes `--source`:

```sh
inkhaven language frequency Eldar --source all     # stored texts + manuscript (default)
inkhaven language frequency Eldar --source prose   # only the manuscript
inkhaven language frequency Eldar --source texts   # only the stored interlinears
```

`prose` scans your manuscript the way `scan-manuscript` does — a paragraph counts
only when it is a conlang context (contains a word from the lexicon), and within it
the words that are listed or *look* like the language become corpus tokens, each
lemma resolved through the auto-gloss index. Ordinary prose in your working language
is left out. The default, `all`, unions the two, so the corpus reflects the language
as you use it across everything you have written.

This applies to all three corpus commands — `frequency`, `concordance`,
`collocations` — and the companion's `/frequency`, `/kwic` and `/coll` now read texts
and prose together.

## Dependencies & compatibility

**No new runtime crates.** Additive — a `build_corpus` assembler and a `--source`
option on the three corpus verbs, reusing `scan-manuscript`'s detection
(`looks_conlang` is now shared) and the auto-gloss index for lemmas; nothing existing
changes. Warning-free (binary and tests). Test suite → 2577.
