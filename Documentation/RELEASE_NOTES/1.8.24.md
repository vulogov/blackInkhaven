# Inkhaven 1.8.24 — TUI responsiveness

_The second hardening cut from the pre-1.9 audit: the one UI freeze is gone, and the
always-on status chips stop rescanning the whole manuscript on every repaint. **No new
runtime crates.**_

## The WordNet lookup no longer freezes the UI

For a language with no local WordNet index — **exactly the Russian case** the AI fallback
serves — `Ctrl+V Shift+Y` used to make its LLM call *synchronously on the event-loop thread*,
so the entire UI hung (no repaint, no input) for the whole round-trip. The call now runs on a
background job; the thesaurus picker opens when it returns, with the "consulting AI…" status
visible in the meantime. Offline WordNet lookups (English, German, …) stay instant as before.

## Status-bar chips stop rescanning every frame

The event loop repaints a few times a second even when idle, so any work in a status-bar chip
runs continuously. Two chips are **on by default** and each did full-hierarchy scans every
repaint:

- the **glossary chip** (`3C·2P·1A`) ran *three* `O(N)` hierarchy scans + subtree allocations;
- the **facts chip** (`⚑N`) ran one more.

Both counts are now cached and recomputed **only on a tree change** (`reload_hierarchy`), the
same way the lexicon already is — so an idle editor with these chips on no longer walks the
whole manuscript several times a second.

## Still to come (item split from the audit)

The larger performance items — caching the per-frame editor highlight/lexicon pipeline, and
holding shared `inner_editor` / `inner_socrates` DB handles (the transient file-lock display
glitch during an engage) — land in a following cut; they touch the hot render path and the
worker plumbing and want their own focused change. The structural **event-driven redraw** (so
idle costs nothing at all) remains a 1.9 item.

## Dependencies & compatibility

**No new runtime crates.** The thesaurus AI fallback moved to a background job (no behaviour
change for offline WordNet); chip counts are cached. Warning-free (binary and tests). Test
suite → 2660.
