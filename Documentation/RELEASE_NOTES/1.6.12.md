# Inkhaven 1.6.12 — Math & Tables

_The finishing pass on the HTML exporter: math renders as MathML, tables as real
tables, bibliographies can be numbered, and an invented language's grammar publishes
in full. No new runtime crates._

## Math → MathML

Math now renders as native **MathML** — drawn by the browser itself, so there is no
JavaScript library, no font download, and the site stays self-contained. It covers the
common Typst-math subset: identifiers and Greek letters, numbers, operators (including
`<=` `>=` `!=` `->`), super/subscripts, fractions (`a/b`), roots (`sqrt(...)`),
parentheses, and the big operators (`sum` `integral` `product` `infinity`); anything
unrecognised degrades to plain symbols.

Both **block** math (a `para:math` paragraph) and **inline** math (`$…$` mid-sentence)
are converted, so a scientific manuscript reads correctly on the web.

## Tables → real `<table>`

A `para:table` (`#table(columns: …, table.header(…), [cell]…)`) now renders as a proper
HTML `<table>` — header row, body rows, and cell formatting intact — instead of raw
markup.

## Numbered bibliographies

`docs.html.citation_style: numeric` produces a numbered (Vancouver-style) bibliography —
`[1] Author. Title. Journal. Year.` — as an alternative to the default author-year list.

## An invented language, in full

When you publish the Language book (`docs.html.include.language`), the grammar now
renders as a complete reference — phonology, morphology, typology, and sample texts —
using the same renderer as the CLI's grammar-book export, alongside the sortable
lexicon table. Previously only the dictionary was rich.

## Dependencies & compatibility

**No new runtime crates.** No new config beyond values already accepted
(`docs.html.citation_style`). Everything is additive — existing projects and exports
are unaffected; math, tables, numbered citations, and the full grammar simply appear
where the content calls for them. Test suite → 2359.
