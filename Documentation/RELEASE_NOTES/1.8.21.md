# Inkhaven 1.8.21 — The Inner Poet remembers (POEM-TUI PO-P16)

_A session store, an ambient mode, and two script words. The Inner Poet now scans a poem
as you open it, remembers its findings across sessions, and lets you silence a complaint you
have decided to live with. **No new runtime crates.**_

## Ambient mode — `Ctrl+B J → P → A`

Toggle **ambient** on and every verse paragraph with a declared form is fast-scanned the
moment you open it — metre and rhyme findings appear in the Output pane without your pressing
`F`. Because the fast track is deterministic and uses no model, ambient is free: no cost cap,
no cooldown, just a fingerprint guard so identical content isn't re-scanned. Off by default;
the toggle scans the current paragraph immediately when you turn it on.

## A session store — `inner_poet.db`

The fast track now persists its findings to `<project>/inner_poet.db` (beside
`inner_editor.db` / `inner_socrates.db`), so a poem's last scan survives a restart and is
available to scripts. Poet findings are deterministic, so the store is a cache and a record —
never a source of truth the tools can't recompute.

## Suppressions — silence what you've decided to keep

The store also records **suppressed** findings: a broken rule you are keeping on purpose (a
deliberately short line, a slant rhyme where the form wants a true one). Suppressing a
finding's key (`severity|kind|line`) stops the fast track and ambient mode from reporting it
again — the scan still counts it, but the Output pane stays quiet, and the status line notes
`(N suppressed)`.

## Two new Bund words

- **`poem.findings`** (`store_read`) — `( paragraph_id -- list )`, the persisted findings for a
  paragraph as `{severity, kind, line, message, key}` dicts.
- **`poem.suppress`** (`store_write`, default-denied) — `( paragraph_id finding_key -- bool )`,
  silence a finding.

`set_form` is intentionally *not* a script word — it writes a sidecar in the manuscript
hierarchy, which the scripting context has no handle on; it stays the editor's
`Ctrl+B J → P → D`.

## Dependencies & compatibility

**No new runtime crates.** The store is built on the in-tree `StorageEngine`, exactly like the
other Inner-family stores. Ambient reuses the shipped fast track. Warning-free (binary and
tests). Test suite → 2659.
