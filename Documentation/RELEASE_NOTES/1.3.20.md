# Inkhaven 1.3.20 — Complement clauses, and a deeper developer's guide

_A focused follow-on to 1.3.19's syntax engine: it adds the last classic syntax
construction, then substantially deepens the beginner's book about the whole
ConLang Suite. No new dependencies. Reference: [CONLANG.md](../CONLANG.md)._

## Complement clauses — the syntax engine is complete

1.3.19 made a language *speak* (sentences, negation, questions, relative clauses,
coordination). 1.3.20 adds the one piece that was still missing:

- **Complement clauses.** **`inkhaven language complement`** builds a sentence
  whose object is a whole clause — "I know *that the bird sees the stone*". The
  matrix subject and verb (`--subject` / `--verb`) wrap an embedded clause
  (`--comp-subject` / `--comp-verb` / `--comp-object`) introduced by an optional
  complementizer (glossed `COMP`). Because the complement fills the matrix
  *object* slot, your word order positions it on its own — an SVO language prints
  it after the matrix verb (`mi tira ya kira nami patan`), a verb-final language
  before it (`mi ya kira patan nami tira`) — and the embedded clause still
  case-marks its own object.

That completes the syntax-depth set: **sentence → negation → questions → relative
clauses → coordination → complement clauses**, all driven by the same typology
answers and paradigms as a plain sentence.

## A deeper *Developing a Constructed Language* guide

The novice book ([`Book/CONLANG_DEVELOPMENT/`](../../Book/CONLANG_DEVELOPMENT/))
grows a whole new part and gets a thorough depth pass.

- **A dedicated interchange chapter.** New Part VIII, *Sharing Your Language*,
  explains moving a lexicon out of and into Inkhaven and the formats the wider
  community uses — Standard Format (SFM/MDF) and the tools that read it (SIL
  Toolbox, FieldWorks, Lexique Pro), PolyGlot, ConWorkShop, CAT tools and XLIFF,
  Anki, and linguex — each with a term box, when-to-use guidance, worked examples,
  a CSV round-trip workflow, and a "what travels and what doesn't" note.

- **A whole-book depth pass.** Every chapter was audited for thin explanations,
  undefined terms, and missing examples. The result: twenty new glossary entries
  (cluster, sandhi, lexeme, syllabary, stop, aspect, mood, definiteness,
  evidentiality, contour tone, syllable weight, quadrat, design grid, and more);
  worked examples added for circumfix, ablaut, and reduplication, for sonority
  sequencing and coda restrictions, for the tone command's output, and for the
  family-tree diagram; the morphology chapter's stale "prefixes and suffixes only"
  note corrected; the typology feature list completed; and complement clauses
  documented in the grammar chapter, the command reference, and the glossary.

- **Typographic fix.** Section headings are now kept with the content that
  follows them, so a heading is never stranded as the last line on a page.

## Design notes

- **Deterministic core.** Complement-clause assembly is a pure, unit-tested
  function reusing the same engine as every other clause type.
- **Backward compatible.** New construction is opt-in; nothing else changes.

Tests 1529 → 1531. **Zero new dependencies.** Full reference:
[CONLANG.md](../CONLANG.md).

## Looking ahead

The next cycle's headline is **full Bund scripting integration for the ConLang
Suite** — an `ink.lang.*` stdlib so scripts can drive the language engine
(generate words, build paradigms, assemble sentences, add words and rules)
through the validated path, not just write raw HJSON.
