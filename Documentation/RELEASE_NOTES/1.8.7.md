# Inkhaven 1.8.7 — Poetry Forms (POEM-1, PO-P1)

_The `poem:` form declaration and the built-in forms library. Declare what a poem *is*
— its metre, foot count, rhyme scheme, and structure — and print a ready-to-paste
template for any of the standard languages. This is the second phase of the POEM-1–7
arc. **No new runtime crates.**_

## The `poem:` block

A poem's declared form is an HJSON `poem:` block (a sidecar or an embedded leaf) — the
thing the Inner Poet will later measure the poem against:

```hjson
poem: {
  form: blank_verse
  metre: iambic
  feet: 5
  metre_tradition: accentual_syllabic
  rhyme_scheme: "-"
  language: en
}
```

## The forms library

Eighteen canonical forms ship compiled into the binary (`assets/poetry/forms.hjson`),
each producible for any project language:

```sh
inkhaven poetry forms                          # list all 18 forms
inkhaven poetry forms --form sonnet --language ru
inkhaven poetry forms --form haiku --language fr
inkhaven poetry forms --new --name my-ode      # a custom-form scaffold
```

The library **localizes** each form to the language you ask for. A Russian sonnet gains
`allow_pyrrhic` and `require_final_stress` (the Russian accentual-syllabic conventions);
a French form switches to the `syllabic` tradition with `elide_mute_e` (French counts
syllables and elides the mute *e*). Forms bundled: sonnet (generic / Petrarchan /
Shakespearean), haiku, senryū, tanka, ghazal, villanelle, pantoum, terza rima, ottava
rima, blank verse, heroic couplet, limerick, ode, elegy, free verse, prose poem.
