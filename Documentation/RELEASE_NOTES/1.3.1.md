## Candidate directions

The remaining 1.3 work, in rough priority order:

- **Standard manuscript format** (finishes pillar A's submission track).  A
  Shunn-style submission render target: monospace double-spaced, 12 pt,
  running headers (author / title / page), `#` scene breaks, rounded word
  count.  A render target, distinct from PDF-1's object-level ops — pairs
  with the existing `inkhaven manuscript` export (1.2.19) and the new PDF
  pipeline (preflight a manuscript-format PDF before submitting).
- **Submission package** — RAG-grounded query-letter / synopsis /
  comp-title helpers (a strong whole-book AI use that doesn't need the full
  1.4 Whole-Book Editor) + a lightweight submission tracker (where sent,
  when, response).
- **The Planning Board** (pillar B — the front of the lifecycle).  Outline
  / beats / acts / turning points + scene cards (goal / conflict /
  disaster) in a corkboard/outline view tied to the Book→Chapter hierarchy
  + timeline + threads.  Integrates the Research book; helps fill the Facts
  book (closing the loop with the 1.2.21 Facts subsystem).

## PDF-1 follow-ups (optional, small)

Now that the subsystem is in users' hands, the likely small asks:

- N-up / booklet quick-impose presets beyond `default` / `chapbook`.
- `pdf cover` front-image bleed/scaling controls; spine-text auto-fit.
- Grayscale coverage for JPEG (`DCTDecode`) images (currently left as-is) —
  needs a JPEG decode/re-encode path, weigh against a new dep.
- Preflight: overprint / transparency / spot-colour checks for true
  print-shop profiles.
