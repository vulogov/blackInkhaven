# Inkhaven 1.3.1 — Submission track (planning)

_Cycle opened on top of 1.3.0 (Print production / PDF-1).  1.3.0 shipped
the print track of pillar A — "From Draft to Submission" — in full.  1.3.1

an agent or editor.  Full plan:
[SUBMISSION-1_PLAN.md](../PROPOSALS/SUBMISSION-1_PLAN.md)._

## Headline — the submission track

The Shunn manuscript *format* already ships (`inkhaven manuscript`,
1.2.19), so the gap is not the format.  Three tracks, sequenced:

- **`.docx` export** — the format agents actually require (Word, not
  PDF/typst).  Pure-Rust (`docx-rs`, audited like `lopdf`; hand-rolled
  OOXML over the in-tree `zip` as fallback).  Shunn layout reusing the
  manuscript metadata + chapter walk.  *Lands first — the concrete
  unblocker.*
- **Submission tracker** — a new `Submissions` system book holding the
  generated prose drafts, plus a structured `.inkhaven/submissions.json`
  sidecar (market / agent / date sent / status / response) with a CLI +
  TUI modal.  *Small; dogfoods bdslib + the sidecar precedent.*
- **Package generators** (AI, RAG-grounded) — query letter, short + long
  synopsis, comp titles, logline, over a cached book digest (the
  whole-book context is the design risk).  A strong whole-book AI use that
  stops short of the deferred 1.4 Whole-Book Editor.  *Lands last.*

## Deferred to 1.3.2+ (pillar B)

- **The Planning Board** — outline / beats / acts / scene cards
  (goal / conflict / disaster) in a corkboard view tied to the Book→Chapter
  hierarchy + timeline + threads; integrates the Research book and helps
  fill the Facts book.  Its own cycle (start with beat-sheet overlays).

## PDF-1 follow-ups (optional, small)

Now that the subsystem is in users' hands, the likely small asks:

- N-up / booklet quick-impose presets beyond `default` / `chapbook`.
- `pdf cover` front-image bleed/scaling controls; spine-text auto-fit.

  needs a JPEG decode/re-encode path, weigh against a new dep.
