# Inkhaven 1.8.5 — The Thesaurus Chord

_WordNet comes into the editor. Put the cursor on a word, press **Ctrl+V Shift+Y**, and a
panel offers synonyms, antonyms, hypernyms, and hyponyms; pick one and it replaces the
word in place. For a language with no WordNet and none to download — Russian — it falls
back to your configured AI. **No new runtime crates.**_

## The chord

In the editor, stand on any word and press **Ctrl+V Shift+Y**. Inkhaven looks the word up
in the WordNet index for the paragraph's language and opens a pick-list — synonyms first,
then hypernyms (more general), hyponyms (more specific), and antonyms, each tagged by its
relation:

```
 Thesaurus · light (en)
  synonym    lite
  hypernym   illumination
  hyponym    daylight, moonlight, sunlight
  antonym    dark
  ↑↓ select · Enter replace · Esc cancel
```

`↑↓` moves, **Enter** swaps the word in place (a normal edit — undoable, saved with the
paragraph), **Esc** cancels. The lookup language follows the prose: the book's language, or
per-paragraph detection when that's enabled. Non-English words expand their taxonomy
through the English pivot by the interlingual index, exactly as the CLI does. The index is
loaded once and cached for the session.

## AI fallback for languages with no wordnet

WordNet covers English, French, German, and Spanish (fetchable) — but not everything. When
a word's language has **no installed index and none to download** — Russian is the case —
the chord falls back to your configured LLM, asking it for the same four relation lists and
presenting them in the same panel. Pick-and-replace works identically. This path uses
whichever provider you've set (it sends the single word to that provider); everything else
is local and offline. If a language *is* downloadable but not yet installed, the chord
points you at `inkhaven wordnet fetch <lang>` instead of quietly using the AI.

## Getting set up

```sh
inkhaven wordnet fetch en fr de es      # install the offline wordnets
inkhaven wordnet import ru ruwordnet.xml # Russian, or rely on the AI fallback
```

The in-app help (`Ctrl+V ?`) documents the chord alongside the rest.

## Dependencies & compatibility

**No new runtime crates.** The chord reuses the WordNet index built in 1.8.3/1.8.4 and, for
the fallback, the existing blocking-completion path (the same one the Inner Editor uses).
Purely additive — a new editor chord and a cached index field; no existing behaviour
changes. Warning-free (binary and tests). Test suite → 2608.
