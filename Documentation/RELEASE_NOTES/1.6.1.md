# Inkhaven 1.6.1 — Harden & Polish

_A consolidation release after the big 1.6.0 "Living World" cycle: a full
stability audit over the new code, two subsystems finished and their `dead_code`
allows retired, a world-choosing command, and a semantic upgrade to the startup
haiku. No new runtime crates._

## Stability pass — an audit over everything 1.6.0 added

A four-track adversarial audit (WORLD compile layers · WORLD desk+CLI · TUI
scene-context · cross-cutting) produced a ranked plan
([`BUGFIX_PLAN_1.6.1.md`](../PROPOSALS/BUGFIX_PLAN_1.6.1.md)); **10 bugs fixed**
across three commits, each with a regression test.

- **P1 — the RTF panic fix was incomplete.** 1.6.0 recovered a panicking RTF
  lexer with `catch_unwind`, but the global crash hook still fired first — writing
  a crash report, printing "inkhaven crashed", and tearing the terminal down even
  though the body was recovered. Now wrapped in `crash::suppress_panic_report`.
- **P1 — the scene-context cache never invalidated.** Mid-session `world.hjson`
  edits and newly-accepted Places were ignored until restart (and made `Ctrl+B W`
  self-inconsistent). The world compile is now keyed on the `world.hjson` mtime,
  and place links are read fresh each paragraph switch.
- **P1 — a declared nation could be silently dropped.** Two declared capitals
  nearest the same settlement collapsed into one; the second is now seated at the
  nearest *unused* settlement.
- **P1 — `realworld travel` overstated north–south distance ~1.5×.** The 160×120
  grid is equirectangular (an x-cell spans more ground than a y-cell); distance
  now scales the axes independently, so a correct N–S journey is no longer flagged
  implausible.
- **P2/P3** — the project lock now covers more store-writers; insert-time
  "contradiction" false positives (numeric detail, comma/decimal formatting,
  idiomatic "no") fixed; a bounds-guarded heightmap write; declared-ecology
  field-by-field merge; saturating distance math; an unknown travel mode now
  warns; `inkhaven style --book-name` matches slug as well as title.

## PDF — bookmark injection, and a subsystem finished

The PDF-1 imposition/print subsystem (`inkhaven pdf`) was already complete;
1.6.1 wires its last built-but-unreachable piece and retires the `src/pdf`
`dead_code` allow.

- **`inkhaven pdf outline --set <TOC>`** injects a bookmark tree from an indented
  `Title :: page` file (indentation nests; 1-based pages). Writes a
  `<stem>-outline.pdf` sibling by default.

## Sources — CSL-JSON export

The SOURCES-1 citation engine was likewise already complete (cite-picker,
`ink.sources.*` Bund, assembly); 1.6.1 adds the export half and retires the
`src/sources` `dead_code` allow.

- **`inkhaven sources export --format bibtex|csl-json`** serializes the Sources
  book's entries — `csl-json` closes the interop round-trip with the existing
  CSL-JSON import (Zotero and other citation managers).

## World — propose several worlds, choose one

- **`inkhaven realworld variants [--count N]`** grows N candidate worlds from
  consecutive seeds and prints a one-line summary of each (continents, sea %,
  settlements, population, dominant biome, top realm) beside the seed that grows
  it — "the world proposes, you choose", now at the world level. Documented in
  *Building the World with Inkhaven* (ch. 3).

## Writer delight — semantic haiku (HAIKU-2)

- When the local embedding engine is already warm, the poem shown on a new
  paragraph or `Ctrl+Z p` is now chosen by **cosine similarity** of your writing
  context against each poem — so a chapter on frost and silence gets a different
  poem than one on ink and beginnings. Startup and any cold-engine moment keep the
  HAIKU-1 rotation. **Zero AI API, zero network**, no latency beyond fastembed's
  first use. Toggle with `editor.haiku_semantic` (default on).

## Dependencies & compatibility

**No new runtime crates.** New commands: `pdf outline --set`,
`sources export`, `realworld variants`; new config `editor.haiku_semantic`; two
`dead_code` allows retired (`src/pdf`, `src/sources`). All additive — existing
projects are unaffected.
