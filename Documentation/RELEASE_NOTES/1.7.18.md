# Inkhaven 1.7.18 — Curating the Translation

_The interlinear's free translation has been auto-generated — a literal, word-by-word
scaffold. Now you can rewrite it. This is the last slice of the Annotation Workbench:
editing a stored text. With it, Track A of the linguistic layer's Wave 4 is complete.
No new runtime crates._

## Editing a stored text

The auto literal translation (`'stone friend'`) is only a starting point; a stored
text can now be given the sentence as it should read. In the Linguistic companion:

```
/texts                                  list your stored interlinears
/settrans oath = The oath was sworn.    curate one's free translation
```

and on the command line:

```sh
inkhaven language texts Eldar --name oath --set-translation "The oath was sworn."
```

Only the free translation changes — the morpheme segmentation and the gloss beneath
it are left exactly as they were. The edit is user-initiated over your own
annotation and is persisted in the tree.

## Track A complete

The Annotation Workbench is done across five slices: auto-gloss (1.7.14), the
morpheme-segmentation line (1.7.15), persistence in a `Texts` chapter (1.7.16),
LaTeX export (1.7.17), and now editing. Your language can be *documented* — a corpus
of glossed, translated, exportable texts alongside its phonology, grammar and
lexicon. Those stored texts are the substrate the coming Corpus Engine will index.
