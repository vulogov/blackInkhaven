# Inkhaven 1.8.26 — Agentic research, part 1 (RESRCH-6)

_The Research Assistant learns to research on its own: give it a topic and it decomposes it,
gathers evidence, and **emits its findings as Facts into the Facts book** — not a standalone
article. The autonomous loop is gated by config, on by default. **No new runtime crates.**_

## `inkhaven research --agentic "<topic>"`

The first slice of deep/agentic research (RESRCH-6). Given a topic:

1. **Plan** — the model decomposes it into a handful of specific, individually-answerable
   sub-questions (bounded by `research.agentic.max_subquestions`, default 6).
2. **Gather** — for each sub-question it researches an answer grounded on the Facts corpus,
   distils a candidate fact, and scores the model's confidence.
3. **Emit into Facts** — above the confidence threshold, each finding is written as a **Facts
   paragraph in the Facts system book**, carrying **`model` provenance** and an **`agentic`**
   thread label, at an **untrusted** tier. The output is the *growing Facts book*, never a
   report you have to reconcile against it.

A Markdown run report goes to `--out` (or stdout). Facts land untrusted **by design** — you
review, promote, dispute, or `/factcheck` them through the ordinary Facts machinery, so
autonomous research never silently trusts itself.

## Integrated with the fact system, not a parallel one

This is a *thin orchestration layer* over primitives that already exist — it reuses the same
single-question chain as `--batch` (retrieve → research → distil → insert), the same
`insert_paragraph` + provenance write path, and the same Facts book. So everything downstream
works natively: fact-check runs against the emitted facts, contradiction detection sees them,
and `/undisputed` and the trust ladder apply.

## Controllable, and on by default

Per the design, the agentic behaviour is a first-class HJSON setting, **on by default**:

```hjson
research: {
  agentic: {
    enabled: true          // set false to disable agentic runs entirely
    max_subquestions: 6    // bounds the sub-questions (and the LLM cost) of a run
  }
}
```

With `enabled: false` the command refuses with a hint; the manual research flow is unaffected.

## What's next (later RESRCH-6 phases)

This cut is a single plan + gather pass. The **gap-driven iterate** step (a critic that
finds unanswered/contradictory sub-questions and loops), the in-loop contradiction gate, and
citation-following (snowball) land in following phases.

provenance. Warning-free (binary and tests). Test suite → 2664.
