# Inkhaven 1.7.7 — The Engine in the Companion

_The Wave-3 analysis engine has lived on the command line; this release brings it
into the Linguistic companion's chat, where you actually think about a language.
Four slash-commands — trace, parse, check, tree — now run locally over your book
and print inline, alongside the grounded conversation. The morphological parser
also learns its first non-concatenative process: full reduplication. No new
runtime crates._

## The analysers, in the chat

The companion's chat already answered `/trace <rule>` with a sound-change preview.
Three more of the Wave-3 analysers join it — each runs against the current
language book and prints its result inline, and none of them commit anything:

```
/parse katakatai
/check tsuki
/tree sees she bird
```

- **`/parse <word>`** runs the morphological parser backwards: it strips your
  language's known affixes from a surface form and reports every analysis that
  bottoms out at a dictionary root.
- **`/check <word>`** is the Oracle — a level-by-level well-formedness verdict
  (phonotactics, then morphology), clean bill of health or specific findings.
- **`/tree <verb> <subject> [object] [indirect]`** builds the clause's X-bar
  phrase-structure tree using your language's declared word order, printing both
  the indented tree and its bracketed notation.

With `/trace`, every Wave-3 analyser is now reachable without leaving the
conversation.

## Reduplication in the parser

The morphological parser now analyses **full reduplication** — the process where a
stem is copied whole to mark plurality, intensity or aspect. `katakata` parses as
`REDUP + kata`, and it composes with ordinary affixes: `katakatai` is
`REDUP + kata + PL`. This is the parser's first non-concatenative process; the
reduplicant halves the remaining length, so the analysis always terminates.

```sh
inkhaven language parse Eldar --word katakata
```

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — three new chat slash-commands
in the companion and a parser extension; existing projects, languages and CLI
verbs are unchanged. The companion book documents the slash-commands and, for the
first time, the full morphosyntax verb set (`parse`, `link`, `tree`, `movement`,
`binding`, `trace`) in its command reference. Warning-free (binary and tests).
Test suite → 2541.
