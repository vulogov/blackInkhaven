# Inkhaven 1.8.29 — Snowball: citation-following (RESRCH-6)

_Follow a paper's citations both ways. Give the Research Assistant a seed paper and it maps
its citation neighborhood on OpenAlex — the works it references and the works that cite it —
so you can widen a literature search from one good source outward. **No new runtime crates.**_

## `inkhaven research --snowball "<seed>"`

The seed is a title, DOI, or topic. Snowball resolves it on OpenAlex (keyless) and follows the
citation graph in both directions:

- **Backward** — the works the seed *references* (what it built on).
- **Forward** — the works that *cite* the seed (what built on it, most-cited first).

It reports the neighborhood as a Markdown list, each paper with its OpenAlex id, e.g.:

```
$ inkhaven research --snowball "attention is all you need"
· seed: Attention Is All You Need  (W2626778328)

## References (backward) — 10 works the seed cites
- Deep Residual Learning for Image Recognition — Kaiming He et al., 2016  openalex:W2194775991
- Effective Approaches to Attention-based Neural Machine Translation — Thang Luong et al., 2015  …
…
## Citations (forward) — 10 works that cite the seed
- An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale — …, 2020  …
…
```

## Reports, doesn't flood

Snowball **surfaces** the neighborhood; it does not auto-ingest. Each result carries its id so
you bring in exactly the ones you want as Sources — `/openalex <title or DOI>` in the research
TUI — keeping the corpus curated rather than swamped, the same review discipline the agentic
loop follows. The Sources you add then feed fact-check and agentic grounding.

Bounded to 10 papers per direction so a run is quick and affordable.

## Dependencies & compatibility

**No new runtime crates.** Built on the existing `scholarly` (OpenAlex) client — the parser now
also extracts a work's references, and two citation-graph queries (`cites:` forward,
`openalex_id:` batch) were added. Gated by `research.scholarly` (on by default). Warning-free
(binary and tests). Test suite → 2665.
