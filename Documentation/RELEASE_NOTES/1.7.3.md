# Inkhaven 1.7.3 — The Analyst's Bench

_Three more read-only analyses round out the linguistic layer's phonology bench —
vowel harmony, positional distribution — and a one-page grammar sketch that
gathers everything the suite computes into a single readable overview. All
deterministic, all instant. No new runtime crates._

## Vowel harmony

Many languages require the vowels within a word to agree on some feature — all
front or all back, all rounded or all unrounded. `harmony` measures how
consistently your lexicon does so, using the distinctive-feature matrix:

```sh
inkhaven language harmony Eldar
```

For backness and rounding it reports the share of words whose vowels agree, and a
verdict — *strong*, a *tendency*, or *none*. A language with real harmony sits
well above the ~50% you would get by chance; one without scatters around it.

## Positional distribution

`metrics` counts how often each phoneme is used; `distribution` reports *where*:

```sh
inkhaven language distribution Eldar
```

It gives the onset and coda inventories and — the interesting part — surfaces
*restricted distributions*: the consonant that only ever appears in codas, or
never starts a word. Defective distributions like these (English /ŋ/ never begins
a word) are a real and common feature of natural phonologies, and worth seeing in
your own.

## A one-page sketch

When you want the whole picture at once, `sketch` assembles it:

```sh
inkhaven language sketch Eldar
```

It renders the phonology (inventory, naturalness, harmony, restricted
distributions, syllable shape), the typology (word order, morphological type,
branching, any marked universals) and the lexicon into three short prose
paragraphs — the analysis dashboard as a page you can read. Unlike the AI grammar
book it needs no provider and is always current. `--out` writes it to a file.

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — three new `language`
subcommands (`harmony`, `distribution`, `sketch`); existing projects and
languages are unchanged. The companion book's command reference is updated to
match. Warning-free (binary and tests). Test suite → 2511.
