# Inkhaven 1.7.14 — Interlinear Glossed Text

_Wave 3 gave the language an engine — generate, parse, judge, diagram. Wave 4 turns
to the **texts** the engine works on. It opens with the linguist's core artifact:
interlinear glossed text (IGT). Give the companion a sentence of your language and
it lays out the Leipzig block — the sentence, a gloss under each word, and a literal
translation. No new runtime crates._

## Interlinear glossed text

`igt` auto-glosses a whole sentence and aligns it as a Leipzig interlinear:

```sh
inkhaven language igt Eldar --text "katai nilo"
```

```
katai     nilo
stone-PL  friend
'stone friend'
```

The gloss line reuses the auto-gloss index, so every inflected form is recognised
(`katai` → `stone-PL`); the literal-translation line takes each word's lexical
meaning, dropping the grammatical tags, as a scaffold you refine. Unrecognised
words — names, coinages not yet defined — pass through untouched. `--json` emits the
structured IGT (the data model that later slices will persist and edit).

It is also a companion command: `/igt <sentence>` prints the same block inline in
the Linguistic companion's chat, alongside `/trace`, `/parse`, `/check`, `/tree` and
`/clause`.

## The Annotation Workbench begins

This is the first slice of Wave 4's Annotation Workbench. It aligns at the word
level (morphemes shown inside the gloss); true morpheme segmentation on its own
line, a curated free translation, and persisting an IGT as a stored, editable
annotation are the next slices.

## Dependencies & compatibility

**No new runtime crates.** Purely additive — a new `conlang::igt` module over the
existing auto-gloss index, a `language igt` verb, and a `/igt` companion command;
nothing existing changes. Warning-free (binary and tests). Test suite → 2562.
