## Carryovers from 1.2.19

### C.1.b — Echo overlay

The echo detector ships as a doctor-scan class.
C.1.b adds a live editor overlay pairing with the
`Ctrl+B Shift+F` style-warning toggle — underline
echoed words in the open paragraph as you write,
not just at scan time.

### C.2.b — Russian + German quantity lexicons + bootstrap

The numeric-contradiction scan bundles English /
French / Spanish lexicons.  C.2.b adds:

* Russian + German number-word / unit / direction
  lexicons (Cyrillic declension + German
  compounding want native-speaker / LLM
  verification before bundling).
* `inkhaven bootstrap-continuity <lang>` — an
  LLM-seed CLI (mirroring `bootstrap-sdt` /
  `bootstrap-prompts`) so any language can be
  seeded + hand-corrected in HJSON.
* Full compound-number parsing ("three hundred
  and forty-two") — C.2 handles digits, single
  number-words, hyphenated compounds, and
  `<number> <scale>` pairs.

### C.3.b — Embedding drift + TUI bible view

* **Embedding-based synonym-aware comparison** —
  C.3 compares continuity-bible values via the
  Snowball stemmer (catches green vs brown,
  tolerates inflection).  C.3.b adds embedding
  similarity so "green" vs "emerald" reads as
  consistent + cross-language facts match
  (бilingual editions).  Needs a public
  `Store::embed(text)` accessor.
* **TUI continuity-bible view** — browse each
  character's extracted facts + flagged drift in a
  modal, instead of the CLI `continuity list` +
  the doctor scan.

### Anachronism overlay (the other half of A.5.b)

Flag period-inappropriate vocabulary against the
project's declared setting — needs
period-vocabulary lexicons, a different lexicon
beast from C.2's quantities.  Pairs naturally with
a genre-packs cycle (mystery + historical
fiction).

## Carryovers from 1.2.18

### R.1.b — ePub polish

* Cover image (configured path or the book's first
  Image node) → EPUB cover + nav landmark.

* Popup footnotes (`epub:type="noteref"` + a notes
  section) instead of the inline span.

### R.2.b — Audiobook polish

* Parallel per-chapter synthesis (CPU-bound) to cut
  the roughly-real-time wall-clock.
* Cover art embedded in the `.m4b` metadata.
* `--bitrate` flag (default 64k).

### R.3.b — `paragraph-too-long` doctor class

A paragraph whose read time exceeds a threshold at
`reading_wpm`.  Info, no autofix — an author-
judgment finding.

### I.1.6 — DuckDB write batching

Deferred from the perf pass per the data (save
path, smaller win than the I.1.4/I.1.5 algorithmic
fixes).  Needs a `_bench-save` instrument first.

### I.1.2.b — In-process bench scenarios

`tree_scroll`, `ai_envelope`, `paragraph_save` —
need in-process access (a subprocess spawn swamps
a sub-millisecond op).  Land alongside a lib+bin
crate split or a hidden `_bench <op>` subcommand
per scenario.

### I.1.1.b — Fixture system-book population

`gen-fixture` ships the user-book backbone;
Characters / Places / Threads + comments + tags
+ a `--no-embed` flag improve bench realism.

## Themes under consideration

### Dialogue & voice

The natural next revision-craft cycle (the
brainstorm's Theme B):

* **Character voice consistency** — pick a
  character + chapter, ask "does X speak in their
  established voice here?" against the Characters
  book.
* **Dialogue-ratio gauge** — % of a chapter that's
  dialogue vs narration.
* **Dialogue-tag detector** — said-bookisms,
  adverb-laden tags, tag overuse.
* **Per-character verbal-tic report** — distinctive
  words each character overuses.

### Genre packs

Mystery + historical-fiction project templates +
style-rule packs (clue tracker, fair-play audit,
the anachronism overlay co-shipping with the
A.5.b remainder).

### AI maturity
