# Inkhaven 1.7.22 — The Hypothesis Register

_The diachronic tools — sound-change, cognates, reconstruct, the Consequence Tracer —
let you test a historical claim one at a time but never *record* it. This release
opens Track C with a register that does: a place to write down your sound-change,
cognacy and borrowing hypotheses, their evidence, and their status as it moves from
proposed to supported or refuted. Historical conlanging, made a method. No new runtime
crates._

## Recording a hypothesis

`hypothesize` records a diachronic or comparative claim in the language's
`Hypotheses` chapter, starting at *proposed*:

```sh
inkhaven language hypothesize Eldar --kind sound-change \
  --claim "k > tʃ / _ i" --note "Northern branch" --evidence "kina → tʃina"
```

`hypotheses` lists the register, each line marked with its status; `hypothesis --id
N` shows one in full; and as the evidence comes in you move it along:

```sh
inkhaven language hypotheses Eldar
#   ? [sound-change] palatalization — k > tʃ / _ i
inkhaven language hypothesis-status Eldar --id palatalization --status supported
#   `palatalization` → supported
```

A hypothesis has a **kind** (sound-change, cognacy, borrowing, other), a **claim**, a
rationale, its **evidence**, and a **status** (proposed → supported / refuted /
retired). Each lives in the tree alongside the language's phonology and lexicon, so
the register is durable documentation of the language's history as you reason about
it. The companion lists it with `/hypotheses`.

The register turns the one-shot diachronic tools into the comparative method itself:
propose a change, trace its consequences, check the cognates it predicts, and write
down whether it held — a refuted hypothesis on the books being as useful as a
supported one.

## Dependencies & compatibility

**No new runtime crates.** Additive — a new `conlang::hypothesis` model, four
`language` verbs, and a `/hypotheses` companion command, persisted the same way the
`Texts` chapter is; nothing existing changes, and the `Hypotheses` chapter appears
only once you record into it. Warning-free (binary and tests). Test suite → 2581.
