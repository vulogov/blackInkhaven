# Inkhaven 1.7.8 — The Oracle Deepens

_The Oracle judged words — are the sounds legal, does it analyse as root plus
affixes? It now judges clauses. Two more levels join it: agreement (does the verb
inflect for its subject?) and argument structure (does the clause have the right
number of arguments for its verb?). Deterministic, and built by reusing the
agreement generator and the argument linker. No new runtime crates._

## Levels 3–4: the clause Oracle

`check-clause` runs the Oracle over a whole clause rather than a single word:

```sh
inkhaven language check-clause Eldar --verb katai --args "she, bird" \
  --verb-root kata --subject-features "number=pl"
```

**Agreement (level 3).** Given the subject's grammatical features and the verb's
root, the Oracle regenerates the verb form the language's agreement rule *should*
produce and compares it to the one you wrote. A plural subject with a singular
verb form is flagged, with the expected form named:

```
✗ [agreement] verb `kata` does not agree with the subject — expected `katai` (V-PL)
```

**Argument structure (level 4).** Reusing the argument linker, the Oracle checks
that the number of arguments matches the verb's valence — an intransitive verb
handed two arguments is flagged, a transitive one handed two is not. The valence
is read from the verb's declared class, or overridden with `--valence`.

A clean clause reports a single line:

```
oracle · clause · Eldar · katai [transitive]
  ✓ a well-formed clause of the language.
```

## In the companion

The Linguistic companion's chat gains `/clause <verb> <subject> [object]
[indirect]`, which runs the clause Oracle's argument-structure check inline
against the current language book (the agreement half needs the subject's
features, so it stays on the command line). It joins `/trace`, `/parse`, `/check`
and `/tree`.

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — one new `language` subcommand
(`check-clause`), one new chat slash-command, and the clause-level Oracle built
entirely from the existing agreement generator and argument linker; existing
projects, languages and CLI verbs are unchanged. The companion book documents
both. Warning-free (binary and tests). Test suite → 2545.
