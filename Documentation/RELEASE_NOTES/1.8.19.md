# Inkhaven 1.8.19 — A poem's shape at a glance (POEM-TUI PO-P14)

_The Outline pane now shows how far along each poem is. Verse paragraphs carry their
glyph, a completion chip (`8/14`, or `14/14 ✓`), and — on the cursor node — the declared
form, its line ratio, and any structural issues. **No new runtime crates.**_

## Completion in the Outline

Open the Outline (`Ctrl+2` or `Ctrl+B Shift+O`) on a book of verse and you can now read its
progress without opening a single poem:

- **Verse glyphs render** — a `para:verse-*` paragraph shows its glyph (`♩` stanza, `‖` line,
  `⁛` quatrain, `⇄` translation, …) instead of the generic prose `¶`, so the shape of a poem
  reads straight off the outline. *(The Tree pane already did this; the Outline had been
  falling back to `¶` — now fixed.)*
- **A completion chip on each verse row** — `8/14` while a sonnet is drafting, `14/14 ✓` (green)
  when a bounded form is complete, or a bare line count for an open form. Scan the outline and
  see at a glance which poems are finished and which still owe lines.
- **The detail panel** (on a wide pane, for the cursor paragraph) adds the declared form, the
  `written/expected · drafting|complete` line, and up to three structural issues — a
  villanelle's missing refrain, a sonnet without its turn — the same reckoning `poetry status`
  prints on the command line. A verse paragraph with no form yet reads
  `no form — Ctrl+B J → P → D`.

All of it reuses the shipped `check_form` engine and is computed only for the on-demand
Outline (visible rows, redrawn on events) — the per-frame Tree render stays untouched, so
there is no cost while you write.

## Dependencies & compatibility

**No new runtime crates.** Reuses `poetry::form_check`; the chip-formatting helper is factored
into the engine and unit-tested. Warning-free (binary and tests). Test suite → 2656.
