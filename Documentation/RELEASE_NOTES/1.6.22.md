# Inkhaven 1.6.22 — The Book's Own Apparatus

_A critical edition is judged as much by its back matter as its argument. This
release lets the finished book carry all four registers — the works, the passages,
the terms indexed by use, and the terms defined — each generated from the prose
itself. Plus sense-level indexing and a small citation affordance. No new runtime
crates._

## The Glossary chapter

`sources.glossary: true` and `inkhaven build` emits a **Glossary** chapter — every
defined term, alphabetical: a scholarly-lexicon term shows its original-language form
(italic) and its numbered senses; an ordinary term shows its definition. It is the
reference a reader consults, as opposed to the index a critic checks, and it joins the
apparatus after the Index Verborum. The heading follows the project language
(Glossary / Глоссарий / Glossaire / Glossar / Glosario).

With the earlier switches, the finished volume now closes with the full critical
apparatus, in order:

- **bibliography** — the works
- **Index Locorum** — the passages
- **Index Verborum** — the terms, indexed by use
- **Glossary** — the terms, defined

## Sense-level Index Verborum

The Index Verborum used to record where a _term_ appears. Now it can record where each
_sense_ appears — tag a use with a plain Typst superscript, the same mark a printed
lexicon uses:

```typst
Pure reason#super[1] demands the unconditioned; but reason#super[2],
the faculty of concepts, cannot reach so far.
```

`reason#super[1]` reads correctly on the page _and_ tells the index which sense you
meant, so the Index Verborum lists, under each sense, the chapters that used the term
in that sense — the finest grain a study of a fractured term can want. Tagging is
entirely optional; an untagged term still indexes at the term level.

## A citation affordance

When you pick a citation whose source has a **reference scheme** — scripture, or
anything you declared one for — the cite picker (`Ctrl+V @`) now inserts `@key[]` and
leaves the cursor _inside the brackets_, ready for the locus. An ordinary source still
gets a bare `@key`. The picker uses the same scheme resolution as the locus validator,
so "loci-citable" means exactly what it does everywhere else.

## Documentation

The _Theology and Philosophy with Inkhaven_ companion manual documents all three — the
sense tag, the glossary switch, and the cite affordance — in a new "Close the volume
with its apparatus" section.

## Dependencies & compatibility

**No new runtime crates.** New config `sources.glossary`; the `term#super[N]` sense
tag (a convention, no new syntax to the format); the scheme-aware cite-picker insert.
Everything is additive and opt-in — an untagged, unconfigured project is unchanged.
Test suite → 2464.
