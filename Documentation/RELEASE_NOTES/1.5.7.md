# Inkhaven 1.5.7 — Research Assistant: comfort & completion (UX · Undisputed)

_A focused follow-on to 1.5.6. It finishes the two Research-Assistant tracks it opened — the UX polish
(**RESRCH-UX P5**) and the authorial-facts feature (**RESRCH-UNDISPUTED P4**) — making the assistant more
comfortable to live in. No new runtime crates._

_Tracks: [RESRCH-UX](../PROPOSALS/RESRCH-UX_TRACK.md) ·
[RESRCH-UNDISPUTED](../PROPOSALS/RESRCH-UNDISPUTED_TRACK.md)_

## Layout & readability (RESRCH-UX P5)

- **Fact quick-view.** In the Facts tree, **`Enter`** on a fact opens a **scrollable modal** with its full
  body (`j/k` scroll · `Y` copy · `Esc` close); `Enter` on a branch folds/expands.
- **Live layout control.** **`<` / `>`** (in the tree or chat) resize the split; **`Ctrl+Z`** zooms the
  focused pane full-screen. *(macOS: `Ctrl+←/→` is Mission Control, so resize uses `<`/`>`.)*
- **Copy to clipboard.** **`y`** in the chat copies the last response; **`Y`** in the tree copies the
  selected fact's body (via the existing `arboard`, with a graceful fallback).
- **Readable chat.** A dim rule separates turns, a **`▼ more`** affordance marks when you're scrolled up,
  and responses now render **light markdown** — **bold**, *italic*, `code`, headings, bullets, links
  (reusing the editor's highlighter; markers are preserved so the scroll math is unaffected).

## Authorial-fact verdicts (RESRCH-UNDISPUTED P4)

- **`/undisputed` now colours the tree.** The common-sense pass persists its per-fact verdicts, and the
  Facts tree **colours each `※` glyph** by the result — **green** plausible · **yellow** odd · **red**
  incoherent — so a glance shows which authorial facts read cleanly and which want a second look. Stored
  in a separate `.inkhaven/fact-undisputed.json` (disjoint from the `/factcheck` verdicts).

## Notes

- **No new runtime crates** (yank reuses `arboard`, already a dependency; markdown reuses the editor's
  `highlight_markdown_lines`). New sidecar `.inkhaven/fact-undisputed.json`.

  RESRCH-2/3/4. The proposed **RESRCH-5** (synthesis & maintenance) and **RESRCH-6** (deep/agentic
  research) remain for the future.
