# Inkhaven 1.7.16 — Stored Texts

_Interlinear glosses have been ephemeral — printed and gone. Now they persist. An
IGT can be saved into a `Texts` chapter of the language book, right alongside its
phonology, grammar and dictionary, and read back later. The beginning of a
documented corpus. No new runtime crates._

## Keeping an interlinear

`igt --save` stores the gloss as a durable annotation in the language's `Texts`
chapter (created on first use, mirroring how the `Dictionary` chapter holds
entries):

```sh
inkhaven language igt Eldar --text "katat nilo" --save --name the-oath-1
```

`texts` then lists what you have gathered, or prints one back:

```sh
inkhaven language texts Eldar                 # list every stored text
inkhaven language texts Eldar --name the-oath-1   # print that interlinear
```

Each stored text lives in the tree — versioned, navigable, and part of what makes
the language documented. The structured form round-trips exactly, so a reopened
text renders the same Leipzig block it was saved as.

## The Annotation Workbench so far

Three slices in: auto-gloss (1.7.14), the morpheme-segmentation line (1.7.15), and
now persistence. A TUI editing surface and export are what remain, and the stored
`Texts` are what the coming Corpus Engine will index.

## Dependencies & compatibility

**No new runtime crates.** Additive — the IGT model gains `Deserialize` for the
round-trip, an `igt --save/--name` flag, and a `texts` verb; existing projects and
languages are unchanged, and the `Texts` chapter appears only once you save into it.
Warning-free (binary and tests). Test suite → 2567.
