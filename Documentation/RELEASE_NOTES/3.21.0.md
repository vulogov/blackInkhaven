# Inkhaven 3.21.0 — Every Answer Checked

_3.21.0 turns the verification track from the keys to the answers. 3.19 and
3.20 probed every surface of the editors and the command line; this release
probes what the editor says back: the vector search, the AI chat, the three
companion TUIs (`inkhaven research`, `inkhaven linguistic`, `inkhaven
worldbuilder`) and the Bund words the documentation names. Sixteen defects
fixed in the search and the chat, five in the companions, six stale words
in the docs, 133 missing short aliases registered, and one feature: an
optional `base_url` per LLM provider for any OpenAI-compatible host. No new
dependency, no new store; warning-free in everything touched. Suite 3273
(+23 ignored)._

## Vector search

A search probe seeds a 120-document project and checks the search functions
and their UI against what they promise. Five defects, all fixed:

**The nearest neighbour is found.** HNSW missed it: a paragraph scoring
cosine 0.881 against a three-word query was absent from the top eight while
the best returned hit scored 0.832. The near-identical `:meta` vectors every
paragraph contributes saturate the graph's neighbour lists (a unit test
reproduces it). A query is now answered exactly by a cosine scan while the
index holds up to 20 000 vectors; above that the graph is walked with a wide
beam. Scores are the exact cosine of the embedded strings, lists are
monotone and duplicate-free.

**Scoped searches search inside the scope.** Facts search (`Ctrl+B Shift+S`),
Book RAG, F1 Help and the similar-paragraph picker post-filtered a small
global pool and came back empty once the manuscript outranked the scope.
The scope is applied inside the vector walk now.

**Moves re-embed.** A paragraph moved to another chapter kept its `:meta`
slot embedding the old path.

**A width change is refused, then repaired.** Changing `embeddings.model`
mixed vector widths silently and every search ranked on garbage. The index
refuses a vector of another width with the remedy, and `reindex` detects the
change, drops the index and re-embeds everything (`MAINTENANCE.md`).

**The similar-paragraph picker is the manuscript's.** It listed Help, Facts
and Prompts paragraphs.

## The AI chat

A chat probe runs the real send path against a keyless stub provider, takes
over the stream channel and feeds tokens, a completion or an error, then
checks the AI pane, the apply keys, cancel / edit / retry, the scopes, the
`/name` prompts, the history ring, persistence, the conversations modal,
fullscreen, selection and search. Eight defects, all fixed:

- **`t` (prepend) goes below the heading.** The reply landed above the
  paragraph's `= Title` line.
- **Book is a sticky scope.** It reset to `None` on send, so its
  conversation view and cached retrieval never applied to the reply. Book,
  Socrates and Editor persist across follow-ups as the reference describes.
- **Cancel disarms the waiting flow.** `Esc` on a stream stopped it but left
  the flow armed: a cancelled rewrite opened its diff review on the next
  ordinary reply, a cancelled fact-check parsed it as findings.
- **`Esc` keeps a finished reply.** It wiped it; the reference promises a
  focus bounce. Streaming → cancel, error → clear and bounce, done → bounce
  and keep.
- **The `/` picker closes when closed.** It was re-derived from the text
  after every key, so the `Esc` that closed it reopened it and the direct
  `/name` send was unreachable. `Enter` on a line matching no row sends it.
- **`/name extra words`** appends the words to the rendered template.
- **Fullscreen history pins by wrapped rows.** In a narrow pane the newest
  turn sat below the fold; search centring had the same drift.
- **A cleared chat drops its retrieval.** It kept showing the previous
  conversation's retrieved passages.

The AI pane title leads with the inference state (`done` / `streaming` /
`error`) so a narrow pane shows it before the chips; a replaced paragraph
no longer ends in blank lines.

## `base_url` for OpenAI-compatible hosts

genai picks the adapter and host from the model name, so a model not spelled
like a frontier model went to local Ollama and no hosted OpenAI-compatible
endpoint could be reached: vLLM or LM Studio on another machine, OpenRouter,
Together, a company gateway. A provider may now set
`base_url: https://host/v1`; the model is sent there through the OpenAI
adapter with the key from `api_key_env` (omit the key for a keyless local
server). Without any `base_url` the client is unchanged. The resolver sees
only the model string at request time, so a model string may belong to one
provider: a shared one is refused at load with the remedy, as is a URL
without an `http(s)` scheme. `auto_fallback`, the `Ctrl+B L` cycle and
`--provider` need no change. `CONFIGURATION.md` row and example, Tutorial 12
section, a commented example in the default project config. Addresses the
generic half of issue #5.

## The companions

Three headless probes drive `inkhaven research`, `inkhaven linguistic` and
`inkhaven worldbuilder` through the shared `TuiHost` hooks over a fixture
project (a Facts chapter, a Note, a World author chapter, the Earth
definition, one language, a stub provider on a closed port): every battery
key in every pane, overlay and map tool at nine sizes, then the documented
contracts — focus and right-pane cycles, size guards, every tree-editing
key, prompt history / `Esc` / completion, chat search, the local commands,
shaping deltas through the `y`/`n` overlay into `/write`, `/wfact` and
`/research`, the interview, the whole map editor including a mouse click,
sessions, and failed streams. Fixed:

**Research: `Enter` on a chapter folds it.** It stepped into the first
fact, and a second `Enter` opened that fact's quick view, which then
swallowed every later key. It folds and unfolds in place now, as documented
and as the other companions do. The manual fact entry (`n`) refuses an empty
body like the confirmation overlay.

**Error turns are not remembered.** A failed stream appends `\n[error: …]`
and the leading newline defeated the placeholder test, so error turns were
saved to the linguistic session and replayed to the model as context in all
three companions.

**Linguistic: `Esc` does not quit.** In navigation mode it quit the app; no
companion quits on `Esc`. It restores the hint line.

**`inkhaven linguistic` is documented.** It had no documentation at all: it
gets a `KEYBINDING.md` section, a `CONLANG.md` section and a
`FEATURE_INDEX.md` row. The research and worldbuilder key tables gain the
verified tree-edit, split, zoom, `q` and empty-body rows.

## The Bund words

`WORD_REFERENCE.md` has been pinned to the policy table since 3.0.6; the
other guides were not checked. Two tests in the default suite now are
(`src/scripting/surface.rs`):

**Every documented word exists.** Every `ink.*` / `calc.*` token named in the
README, the guides, the Bund docs and the tutorials must be a registered
word, an alias or a namespace. Six had drifted: the `ink.now` / `ink.fmt` /
`ink.print` examples, `ink.key.bind_view_sub`, and the never-shipped
`ink.snapshot.set_annotation` and `ink.stylist.coach_blocking`. All fixed.

**Every word answers to its short alias.** The reference has promised it
since 3.0.6: the same name without `ink.`. 133 words had none. The stdlib
registers the short form generically after every module; a short name
bundcore owns (`input`) or another word claimed first (`world.check` is
`calc.world.check`'s) is left alone and listed in the reference.

## Upgrade notes

**Search results change** where they were wrong: a project under 20 000
vectors is now searched exactly, so a hit that HNSW missed appears and the
ranking is the true cosine order.

**Switching `embeddings.model`** to a model of another vector width now
refuses the first embedding with a message naming the remedy; run
`inkhaven reindex` once and the index is rebuilt at the new width.

**`Esc` in the AI pane** keeps a finished reply on screen and bounces to the
prompt; it used to wipe the reply.

**`Esc` in `inkhaven linguistic`** no longer quits; use `q`, `Ctrl+Q` or
`Ctrl+C`.

**`Enter` on a chapter in `inkhaven research`** folds the chapter instead
of stepping into its first fact; `l` steps in.

**Short Bund aliases** exist for every `ink.*` word. A program that defined
its own word under one of those short names keeps it: an alias is never
registered over an existing word.

**`providers.<name>.base_url`** is optional; configurations without it load
and behave exactly as before. Two providers naming the same model string is
refused at load only when one of them sets a `base_url`.

**Existing projects open unchanged**; no on-disk shape moved.
