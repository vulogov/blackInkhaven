# Inkhaven 1.10.0 — The Cartographer

_The worldbuilder learns to draw. 1.10 adds an interactive map editor — place towns,
draw rivers, mark regions, and check them against the physics, all from the terminal —
plus seed exploration and a real painted map on capable terminals. Every edit is still
an ordinary `world.hjson` change; the tool measures, validates, and records._

## The interactive map editor (MAPED, Tier 1)

Cycle the worldbuilder's right pane to **Map** and press **`e`** to edit. A crosshair
moves over the compiled world (`hjkl`/arrows, `Shift` for a single cell) with a readout
of the coordinate, biome, and elevation under it. Then the tools:

- **`t`** place a town/settlement · **`n`** a named landmark → drawn `⌂`, written to
  `geography.landmarks[]`.
- **`r`** draw a river: move to the source and `Enter`, to the mouth and `Enter`, then
  name it → drawn `≈`, written to `hydrology.rivers[]`. The course is **validated as you
  draw** — "runs uphill", "mouth above the shoreline", "off the map".
- **`g`** place a region, its biome auto-filled from the cell under the cursor → drawn
  `§`, written to `geography.regions[]`.
- **`d`** delete the feature under the cursor.
- **`/mapcheck`** checks the whole map layer against the compiled world — a town in the
  ocean, an off-map coordinate, a region in the sea — flags each offending cell `!`, and
  **`f`** jumps the cursor from one issue to the next.

Every placement is a pending edit: review the batch with `/diff`, commit atomically with
`/write`. Because these are ordinary `world.hjson` declarations, the compiler honours
them (a declared river carves its course) and they appear on the plakat raster too.

## Worlds you can see and explore

- **`/roll [n]`** — the compile is seed-deterministic, so one declaration implies a whole
  space of worlds. `/roll` compiles *n* candidates on derived seeds and compares them
  (continents · sea % · population · climate · ★); **`/adopt <seed>`** sets one.
- **The raster map** — on image-capable terminals (kitty / iTerm2 / sixel), `/map` paints
  the real plakat-rendered map in the Map pane; elsewhere the ASCII biome map stands in.

## Sessions, promotion, and export

- **`/switch <name>`** — switch between named worldbuilder sessions in-place (each keeps
  its own pending delta and journey).
- **Research pane** — `j`/`k` over hits, `a` promotes a passage to a `fact:world`.
- **`/export --pdf`** — render the world dossier to PDF in-process via Typst (all prose
  is emitted as string literals, so any language or punctuation is safe).

## Compatibility

No new dependencies. Every change is additive and backward-compatible: `geography.regions[]`
gains an optional anchor cell (legacy descriptive regions still parse); the pending-delta
engine gains a `RemoveAt` op. Nothing changes the existing compiler, fact-checker, or any
project. Compiles warning-free. Test suite → 2720.
