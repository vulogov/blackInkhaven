# Inkhaven 1.8.22 — The poetry capstone (POEM-TUI PO-P17)

_The documentation catches up with the tools. A new editor chapter in the poetry companion
book, a ninth track in the author's guide, and the reference docs updated for verse. This is
the capstone of the POEM arc — the last phase. **No code changes; no new crates.**_

## "Writing a poem at the desk" — _Poetry with Inkhaven_

The companion book gains a ninth chapter (a new Part V, _At the Desk_) that walks the whole
in-editor loop end to end: making a verse paragraph, declaring its form with `Ctrl+B J → P →
D`, writing with the live syllable readout, growing the poem with `Ctrl+B Shift+Y`, reading it
back with `F` / `E` / ambient, suppressing what you keep on purpose, seeing completion in the
Outline, and reviewing a translation with `T`. The TUI screens are drawn as faithful
monospace terminal frames — a truer picture of a terminal UI than a flowchart, and the book
stays self-contained and warning-free. (67 pages, up from 59.)

## The poetry track — _Developing a story with Inkhaven_

The author's guide grows from eight tracks to **nine**: a new Chapter 11, _The poetry track_,
takes its place beside fiction, nonfiction, theology, and the rest. It follows the same
Frame → Gather → Read → Produce → Hands-on loop as every track guide, framed around the two
things poetry declares — the `genre: "poetry"` that stands the prose readers down, and the
`poem:` form the Inner Poet measures against. Every "eight tracks" roster (the introduction,
the tracks chapter, the conclusion) is updated; the conclusion is renumbered to Chapter 12.

## Reference docs updated for verse

- **STRUCTURAL_PARAGRAPHS.md** gains a _Part C — Verse paragraphs_: the six `para:verse-*`
  types, how to create them, the `poem:` form-declaration block, the `---` / `⇄` translation
  delimiter, and what the Inner Poet adds.
- **KEYBINDING.md** documents the full `Ctrl+B J → P` Inner Poet family (`F` / `E` / `D` / `T`
  / `A`).
- **CONFIGURATION.md** documents the `genre: "poetry"` value and what it recalibrates.

## The POEM arc, complete

Eighteen phases across seventeen releases (1.8.6 → 1.8.22), **zero new runtime dependencies** —
from the first verse tag to a full prosodic workbench with its own companion book: scansion,
rhyme across five languages, the Inner Poet (fast + slow + ambient), form completion, the
translation trilemma, a session store, and the whole editor workflow. Throughout, one
discipline held: observe, measure, report — never generate a line of verse.

## Dependencies & compatibility

**No code changes and no new crates.** Documentation and companion-book updates only; both
books compile warning-free with a bare `typst compile`. Test suite unchanged → 2659.
