# Inkhaven 3.4.0 — Export Fidelity & a Smoother Revision Loop

_Another **widen-and-polish** release: no new capability. It deepens the export
formats you already have — so more of your manuscript survives the trip out — and
tightens the Editorial Pass revision loop._

Two tracks. Deterministic, no new runtime crates.

## Track X · Export fidelity

An audit of every export path found one lossy bottleneck with outsized leverage
and a handful of format-specific holes. Fixed, ranked by reach:

- **`typst_to_markdown` — the shared converter (one fix, three formats).** It feeds
  markdown export, `export epub`, *and* the HTML prose path, so its losses were
  tripled. Now: **`#figure(image(...))`** renders `![alt](path)` (the wrapped form
  used to leak as literal code); **inline `#footnote[body]`** becomes a `[^N]`
  marker plus a `[^N]: body` definition list (balanced-bracket aware); and
  **`@key` / `@key[locus]`** references become pandoc-style `[@key]` /
  `[@key, locus]` instead of leaking literal source. (The module doc, which
  overstated support, was corrected.)
- **docx / Shunn PDF — authored emphasis renders.** `*bold*` / `_italic_` were
  flattened to literal `\*bold\*` in both the Word doc (one plain run) and the
  Shunn-format PDF (over-escaped). A shared tokenizer now emits real `<w:b>`/`<w:i>`
  Word runs and keeps the `*`/`_` as typst markup in the PDF — **central for
  fiction** (italics for thoughts / emphasis). Title page, running header, scene
  breaks, and page breaks are untouched.
- **`export epub` — the rich builder.** The CLI `inkhaven export --format epub`
  produced a *single-chapter* toy epub; it now routes to the same rich,
  multi-chapter builder as `inkhaven epub` (a `nav` entry per chapter, embedded
  images, EPUB3 footnote popups, cover). (The pipeline filters
  `--status`/`--tag`/`--profile`/`--blind` don't apply to EPUB — a note says so.)
- **HTML verse.** `para:verse-*` fell through to the prose path and its line breaks
  collapsed — the one hole in the otherwise-rich HTML exporter. Verse now gets a
  `<div class="verse">` with `<p class="stanza">` blocks and `<br/>` line breaks,
  keeping inline emphasis.

**Left as follow-ups** (audit-flagged, deferred): the Scrivener non-ASCII
structured-RTF import, the EPUB-import footnote/table round-trip, and full
retirement of the `build_epub` toy (still used by the Bund `ink.export.epub` word
and the TUI batch exporter, which build in-memory artefacts).

## Track E · Editorial Pass, round three

The revision loop kept resetting: jump to a finding, fix it, reopen the pass — and
you were back at the top. Now the pass **remembers your place**. On jump (`Enter`),
act (`f`), or the `F` batch, it saves your filters and position; on reopen it
restores the filters and lands on the same finding — or, if you just fixed it, on
the **next** one. A deliberate `Esc` forgets the position (fresh next time), and
the `F` batch **auto-reopens** the pass when it finishes, so triage continues
without a manual `Ctrl+V Shift+R`.

## Platform note

Supported release targets remain **Linux** (`x86_64-unknown-linux-gnu`) and
**macOS** (`aarch64-apple-darwin`). Windows stays deferred (the `ort-sys` ONNX
bindings ship no windows-gnu prebuilt).
