# Inkhaven 1.8.4 — WordNet Goes Multilingual

_The thesaurus reaches the standard languages. `wordnet fetch` now installs **French,
German, and Spanish** alongside English, and a non-English lookup inherits English's rich
relation taxonomy through the interlingual index. **Russian** is supported by import,
since it has no open distribution. The only new crates are a pure-Rust xz decoder and the
`tar` reader — no external binaries._

## French, German, Spanish

```sh
inkhaven wordnet fetch en fr de es
inkhaven wordnet lookup perro --lang es
```

The OMW language wordnets ship as `.tar.xz`; Inkhaven now unpacks them (pure-Rust `xz` +
`tar`, no `liblzma` / external binary) and builds each index the same way as English.
Spanish *perro*, French *chat*, German *Hund* all resolve to their senses and synonyms.

## Cross-lingual relations through the ILI

A translated wordnet typically lists the *lemmas* of each concept but not its
hypernym/hyponym links — those live in the English backbone. Inkhaven bridges the gap
through the **interlingual index (ILI)**: when a word's native synset has no taxonomy
relations, its ILI is followed into the English wordnet's relation graph and the results
are mapped back to the query language's lemmas. So Spanish *perro* gains

```
  hypernyms  animal doméstico, cánido
  hyponyms   basenji, cachorro, caniche, dálmata, mastín, pug, …
```

drawn from English's relations but rendered entirely in Spanish. (Install `en` for this
to work; synonyms are always native.)

## Russian, by import

Russian has no openly-redistributable wordnet — the best resource, RuWordNet, is under a
research licence. Rather than bundle it, Inkhaven lets you bring your own:

```sh
inkhaven wordnet import ru path/to/ruwordnet.xml
inkhaven wordnet lookup свет --lang ru
```

`wordnet import <lang> <file>` builds an index from any local WN-LMF document (`.xml`,
`.xml.gz`, or `.tar.xz`) — the same path any language could take. `wordnet list` shows
the sources, their licences, and what's installed.

## Robustness — versioned indexes

Built indexes now carry a version header, so an index from a build whose layout differed
is rejected with a clear *"re-run `wordnet fetch`"* message instead of being silently
misread (which previously could make cross-lingual relations quietly disappear).

## Dependencies & compatibility

Adds two crates for unpacking the OMW archives: `lzma-rs` (a **pure-Rust** xz decoder — no
`liblzma`, no external binary) and `tar` (promoted from a transitive dependency). Purely
additive — `wordnet` gains an `import` subcommand and three fetchable languages; no other
command changes. Warning-free (binary and tests). Test suite → 2603.
