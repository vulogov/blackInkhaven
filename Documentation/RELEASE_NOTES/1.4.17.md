# Inkhaven 1.4.17 — The startup haiku

_Every time Inkhaven opens, you sit down to make something. The blank-page moment is real. HAIKU-1
puts a small, hand-curated poem in the Output pane to meet it — and gives the pane its first piece of
**good news** (until now it spoke only in warnings, findings, and task completions). It is the
simplest feature in Inkhaven: **no AI, no network, no generation.** All 25 poems (five per language,
EN/RU/DE/FR/ES) are hand-written and baked into the binary — present in the first millisecond of
startup, before the database journal replays, even on an airgapped machine. **No new crates.**_

_Plan: [HAIKU-1_PLAN.md](../PROPOSALS/HAIKU-1_PLAN.md)_

## Three moments

- **Startup** — one haiku lands in the Output pane when the project opens.
- **A new manuscript paragraph** — the instant you create a prose paragraph in a *user book* and open
  it to write, a fresh haiku meets you in the blank buffer. (Only real manuscript prose: never
  Characters/Places/Notes entries, Dictionary/Sources/Glossary/Snippets/Threads, or
  structural/template paragraphs.)
- **On demand — `Ctrl+Z p`** — when you want the pocket of stillness mid-session, press `Ctrl+Z p`
  (P for Poem). The status bar confirms `✦ haiku written to Output`; your focus doesn't move.

The poem is in the book's language (`editor.language`); an unsupported language falls back to English.
A per-process rotation (seeded from the clock so each launch differs) advances on every trigger, so
you rarely see the same poem twice in a session.

## What you'll see

A `✦ haiku` row in the Output pane with the three lines beneath it:

```
✦ haiku
   Blank page catches light —
   the sentence that wants writing
   waits inside the pen.
```

Only the most recent haiku ever lives in the pane — a new one quietly replaces the last, so they never
pile up. Each language carries three **Tier-A** poems (the manuscript — ink, the blank page, the first
sentence) and two **Tier-B** poems (the writer's surroundings — rain on the glass, a lamp's circle,
the pause between words); the Tier-A poems come first in rotation.

## Turning it off

```hjson
{ editor: { startup_haiku: false } }
```

That silences the startup and new-paragraph moments. The `Ctrl+Z p` chord still works whenever you
want one.

## Notes

- **Scripting** — none; the feature is purely a TUI delight.
- **No new runtime crates; no new system books; no new `NodeKind`; no new DuckDB file.** One module
  (`src/haiku.rs`), one Output kind (`✦ haiku`), one config knob (`editor.startup_haiku`, default
  `true`), one chord (`Ctrl+Z p`). New tutorial 100. Tests 2103 → 2106.
