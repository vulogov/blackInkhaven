# Inkhaven 1.8.18 — Building a poem at the desk (POEM-TUI PO-P13)

_Fluid stanza-building and a live syllable readout. Write a poem the way you'd write a
poem — one stanza after another — and watch each line's syllable count as you go. **No new
runtime crates.**_

## Next stanza — `Ctrl+B Shift+Y`

Press **`Ctrl+B Shift+Y`** and Inkhaven creates the next stanza: a sibling verse paragraph
of the **same** `para:verse-*` type, placed right after the current one and opened for
editing. Build a sonnet stanza by stanza — or a villanelle tercet by tercet — without
reaching for the tree, the type picker, or the mouse. It works on the open buffer or the
tree cursor, and no-ops with a hint if the paragraph isn't verse.

As always: it writes **structure only**. It never generates a line of verse.

## A live verse readout

While a verse paragraph is open, the status bar now carries a live poetry chip:

```
♩ 8 syl · l2/4
```

— the **syllable count of the line your cursor is on**, updated as you type, plus the
line's position in the stanza. It answers the question a metrical poet asks a hundred times
a session — *is this line at its ten? is this haiku line at its five?* — without running a
command. It counts in the project's language, so it's as exact for Russian as it is
approximate for English (the honest limit the companion book documents).

## Also: a keybinding fix

Freeing `Ctrl+B Shift+Y` surfaced a latent bug: the **WordNet thesaurus** had been bound to
`Ctrl+B Shift+Y` even though its name (`view.open_thesaurus`) and its docs since 1.8.5 both
say **`Ctrl+V Shift+Y`**. It is now where it was always documented to be — on the Ctrl+V
(view) layer. If you reached the thesaurus with `Ctrl+B Shift+Y`, use `Ctrl+V Shift+Y`.

## Dependencies & compatibility

**No new runtime crates.** Reuses the shipped node-creation and status-chip machinery. One
keybinding moved (thesaurus → its documented `Ctrl+V Shift+Y`); a regression test now pins
both `Shift+Y` chords so they can never collide again. Warning-free (binary and tests).
Test suite → 2655.
