# Inkhaven 2.2.0 — SENTINEL: Continuity Intelligence

_Inkhaven could already **check** a manuscript's continuity — but only if you knew
which of six separate commands to run, each with its own sidecar and mental model.
A character in two places at once was one command; a number that contradicts
itself another; a character whose eyes changed colour a third. Nobody watched them
together, and nothing watched them as you wrote._

The flagship of 2.2.0 is **SENTINEL** — continuity intelligence. Its thesis:

> **Continuity already exists in pieces. SENTINEL unifies them over the knowledge
> graph, adds the one invariant nobody had, and watches incrementally as you write.**

It is **advisory** (it flags, it never rewrites), its core is **deterministic and
free** (no LLM), and it adds **no new runtime crates** — it is the payoff of 2.0's
knowledge graph, which is what makes *unified* and *incremental* continuity feasible.

## Unify

One engine runs every deterministic continuity detector already in the tree,
normalises each into a single finding shape, dedupes, and ranks (Contradiction >
Warning > Info; earlier chapters first):

- **`co_location`** — a character in two places at overlapping times (from the
  timeline; magic-ledger suppressed).
- **`timeline`** — orphaned events and fuzzy-precision overlaps.
- **`numeric`** — a direction reversed or a duration that contradicts itself (EN/FR/ES).
- **`char_facts`** — an established fact changed across chapters (over the extracted
  `.inkhaven/continuity.json` — SENTINEL reads it, it doesn't re-extract).

`inkhaven continuity check` prints the ranked ledger (`--only` / `--skip` by
detector, `--json`, **non-zero exit on any Contradiction** for CI).

## Complete — the invariant nobody had

**Referenced before introduced.** An entity's *introduction* is its first scene
(the earliest paragraph its timeline events touch); a *reference* is any mention in
the prose. Name a character chapters before they step on stage and SENTINEL catches
it: *"'Aldous the ferryman' is referenced in ch. 2 but not introduced until ch. 5."*
Same-chapter foreshadowing never flags (`introduce_tolerance` widens the lead-in);
names come from your own Characters/Places books and the match is Unicode-aware, so
it works the same in Cyrillic or accented scripts as in Latin.

## Watch — the book watches itself

Turn on `continuity.ambient` and every save re-checks only what the edit touched —
the paragraph's entities and chapter, read from the graph — and surfaces the delta
immediately. Deterministic and free, so it runs inline. This is the SEMNET payoff:
the edited paragraph's edges tell the engine exactly what to re-check.

## The surfaces

- **The review pass** (`Ctrl+B Shift+C`) gains a `continuity` line — each finding
  anchored, in the Output pane's `continuity` category.
- **The ledger dashboard** (`Ctrl+B Shift+I`) — a scrollable modal of the ranked
  findings grouped by kind. `↑↓` scroll, **Enter** jumps to a finding's paragraph,
  **`k`** runs the coherence pass, `Esc` closes.
- **The coherence pass** — the one fuzzy check SENTINEL *invokes* but never runs
  automatically: an LLM reads a run of paragraphs for the cross-paragraph
  contradictions the patterns can't see (a fact asserted then quietly reversed).
  Explicit, cost-capped, opt-in — `continuity check --coherence` or `k` in the
  ledger. It reuses the world fact-checker's coherence machinery; no LLM logic is
  re-implemented.
- **`ink.continuity.*` Bund words** — `findings` ( -- list ) and `check` ( -- dict ),
  read-only, so scripts and hooks read the ledger.

## Configuration

```hjson
continuity: {
  enabled: true              // the review-pass ledger master switch
  ambient: false             // re-check the edit's scope on every save
  ambient_cooldown_secs: 30
  co_location: true, timeline: true, numeric: true, char_facts: true, introduce: true
  introduce_tolerance: 0     // chapters of "referenced early" tolerated
}
```

All knobs inform and cap — per Inkhaven's permissive principle, they never block.
The existing `timeline.critique` and `editor.echo_*` knobs are untouched; this
block only adds.

## Multilingual

SENTINEL inherits each detector's language coverage and never claims more. The new
`introduce` invariant is language-safe everywhere; `co_location` / `timeline` /
`char_facts` are multilingual as built; `numeric` is EN/FR/ES (it skips cleanly for
other languages). Every finding carries its `source`, so *"does it work in
Russian?"* answers itself per detector.
