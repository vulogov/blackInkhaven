# Inkhaven 1.6.21 — The Scholarly Lexicon

_A study's citations can be perfect and its argument still fail on a single word.
This release keeps a work's *terms* as disciplined as its citations: a Glossary
entry can now carry its original-language forms and its distinct senses, the rigor
reader gains an equivocation signal, and the finished book grows an Index Verborum.
No new runtime crates._

## The scholarly lexicon

The Glossary was built for *consistency* — one canonical form, ban the variants.
Philosophy and theology need the opposite discipline: their load-bearing terms
(_reason_, _being_, _grace_, _law_) legitimately carry several senses, and the danger
is sliding between them. A Glossary entry now records that:

```hjson
term: reason
original_forms: [ Vernunft ]
senses: [
  { label: Vernunft   gloss: the faculty of the unconditioned }
  { label: Verstand   gloss: the faculty of concepts }
]
watch_equivocation: true
```

The new fields — `original_forms`, `senses`, `watch_equivocation` — are all
optional, so every existing glossary is untouched.

## Equivocation — the rigor reader's sixth signal

When I shipped the reasoning-rigor reader in 1.6.20 I left equivocation out, because
deterministic marker-matching cannot know a term has senses to shift between — the
ambiguity is in the world, not the words. The lexicon supplies exactly that
knowledge. A term declared multi-sense and `watch_equivocation` is now policed: when
it recurs in a paragraph without one sense pinned, `Ctrl+B J → R` (and `inkhaven rigor
scan --signal equivocation`) flags it — *"'reason' recurs here and carries more than
one declared sense; is it used in one sense throughout?"*

You curate the danger: mark the handful of terms your argument turns on, and the
reader watches exactly those, in any of the five project languages, and nothing else.
Toggle it with `rigor.equivocation`.

## The Index Verborum

The term-level twin of the Index Locorum:

```
inkhaven index-verborum                   # Markdown (also --format typst|json)
inkhaven lexicon list                     # inspect the lexicon terms + senses
```

`index-verborum` lists every lexicon term the manuscript actually uses — its
source-language form, its senses, and the chapters that use it — the glossary a
critical edition prints at the back. Set `sources.index_verborum: true` and `inkhaven
build` folds it into the finished book after the Index Locorum, so a volume closes
with all three apparatus in order: the works (bibliography), the passages (Index
Locorum), and the terms (Index Verborum) — each generated from what the prose actually
contains.

## Documentation

The _Theology and Philosophy with Inkhaven_ companion manual gains a "Keep your terms
honest" section in its citation chapter, completing the arc's four disciplines:
grounded claims, validated citations, valid arguments, and now precise terms.

## Dependencies & compatibility

**No new runtime crates.** New commands `inkhaven lexicon list` and `inkhaven
index-verborum`; new Glossary fields (`original_forms`, `senses`,
`watch_equivocation`) and config (`rigor.equivocation`, `sources.index_verborum`) —
all opt-in. A transitive dependency (`spin`) was bumped off a yanked patch. Everything
is additive; existing projects are unaffected. Test suite → 2462.
