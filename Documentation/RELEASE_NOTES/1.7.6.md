# Inkhaven 1.7.6 — The Syntax Engine

_A sentence has structure, and this release builds it. The linguistic layer gains
a generative syntax engine: it draws the X-bar phrase-structure tree of a clause,
fronts constituents leaving traces, and decides which pronouns may refer to which
antecedents by c-command. All deterministic. No new runtime crates._

## The phrase-structure tree

`tree` builds the X-bar tree (CP → TP → VP) of a clause from its subject, verb and
objects, placing heads and complements by the language's word order:

```sh
inkhaven language tree Eldar --verb sees --args "she, bird"
```

```
CP
├─ C ∅
└─ TP
   ├─ NP
   │  └─ N she
   └─ T'
      ├─ T ∅
      └─ VP
         └─ V'
            ├─ V sees
            └─ NP
               └─ N bird
```

A head-final (SOV) language reverses it correctly — the object precedes the verb,
VP precedes T, TP precedes C. Specifiers sit left; the head–complement order is the
one parameter, read from your grammar block.

## Movement

`movement` fronts a constituent — the operation behind wh-questions and
topicalisation — leaving a coindexed *trace* in the position it vacated:

```sh
inkhaven language movement Eldar --verb sees --args "she, bird" --move object
```

The object lifts to the specifier of CP as `NP₁`, and a trace `t₁` marks where it
came from — the derivation made visible.

## Binding

`binding` decides whether one argument of a clause may refer to another, from the
structure and the binding principles:

```sh
inkhaven language binding Eldar --verb sees --args "she, herself" --type reflexive
```

The engine is *c-command* — a node c-commands its sibling and everything the
sibling dominates. A reflexive object **may** bind to the subject that c-commands
it (Principle A); a pronoun in the same position **may not** (Principle B); a name
is a Principle-C violation. The relation is correctly asymmetric — the subject
c-commands the object, but not the reverse.

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — three new `language`
subcommands (`tree`, `movement`, `binding`); existing projects and languages are
unchanged. The companion book's command reference is updated to match.
Warning-free (binary and tests). Test suite → 2539.
