# Inkhaven 1.3.3 — The Planning Board, fluent & complete (planning)

_On top of 1.3.2 (The Planning Board).  1.3.2 shipped the analyze + pacing
slice; 1.3.3 makes the Board **fluent** (map beats without hand-editing
HJSON) and **complete** (the blank-page / plan-first mode), then sweeps the
deferred loose ends.  Full plan:
[PLANNING-2_PLAN.md](../PROPOSALS/PLANNING-2_PLAN.md)._

## Headline

- **Interactive mapping** — `plan map`/`unmap` write-back + an interactive
  `Ctrl+V Shift+K` outline (map a beat to a chapter from a picker, jump to
  its chapter, cycle status, link threads). Kills the slug-hunting friction.
- **Plan-first scaffolding** — `plan scaffold --premise "<logline>"`
  expands each framework beat into an intention; `--chapters` materializes
  chapter shells from the beats (opt-in, guarded). The blank-page mode.
- **Consolidation** — `actions/checkout@v5`; a `stale-submission` doctor
  scan; the CLI Prompts-book prompt tier; `I`-lift of a streamed draft into
  its system book.

## Landed so far

- **Planning Board — slug discovery.** `inkhaven plan check` now ends with
  a **CHAPTER SLUGS** list (the values to put in a beat's `mapped_chapter`)
  and a **THREAD SLUGS** list (for `threads`), so you can map beats without
  hunting for slugs in the filesystem.  Tutorial 67 expanded with a worked
  mapping example.
