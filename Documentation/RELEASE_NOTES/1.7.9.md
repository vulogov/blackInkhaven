# Inkhaven 1.7.9 — The Oracle Watches

_The Oracle has judged words and clauses on demand. Now it watches your prose. Save
a paragraph and the phonotactic guardian checks the invented-language words in it —
flagging any that break their language's own rules, as an advisory Output finding.
Zero-AI, deterministic, and it never touches a syllable of your writing. No new
runtime crates._

## The on-save phonotactic guardian

When you save a paragraph, the Oracle scans it for conlang words — words that
segment fully into one of your languages' inventories but aren't in its dictionary
— and flags any that violate that language's phonotactics. The finding lands in the
Output pane (`Ctrl+B` → `Tab`), marked `⌥`:

```
⌥ [Eldar] `ktal` breaks phonotactics — contains an illegal onset cluster
```

It is the mirror image of `scan-manuscript`: where that lists the *well-formed*
words you have not defined yet, the Oracle flags the *ill-formed* ones — the typos
and malformed coinages that break your own rules. The two share a precision guard:
both only speak up in a paragraph that already contains a listed word of the
language, so prose written in your working language is left alone. A well-formed
undefined word is `scan-manuscript`'s business, so the Oracle stays silent on it.

Multi-language projects are scanned language by language, each against its own
phonology. The check is purely advisory — it emits an Output finding and nothing
more; it never edits your prose.

## Configuration

A new `oracle:` block controls it, on by default:

```hjson
oracle: {
  enabled: true   // master switch for the Oracle
  on_save: true   // run the phonotactic guardian when a paragraph is saved
}
```

Projects with no languages never trigger it.

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — a new pure `oracle::scan_prose`
(the complement of `scan-manuscript`), a new advisory Output kind (`oracle`, `⌥`), a
new `oracle:` config block, and one post-save hook; existing projects, languages,
and prose are unchanged, and the guardian is a no-op until a project has languages.
The companion book documents it in the healthy-lexicon chapter. Warning-free (binary
and tests). Test suite → 2549.
