# Inkhaven 1.2.21 — The Facts book

_Theme: a first-class home for the **facts** a book's world
runs on — climate, geography, seasons, distances,
chronology — and the AI plumbing to write against them and
check prose for contradictions._

Early on, an author collects research in the **Notes** and
**Research** system books — loose plot notes, source
material.  But the *invariants* of the world (it's winter
in this hemisphere; the capital is three days' ride from
the coast; the war ended a generation ago) are a different
kind of thing: they're the ground truth every chapter must
stay consistent with.  1.2.21 gives them a dedicated
**Facts** system book and wires the AI to treat it as the
authoritative reference.

Four parts, one dependency chain (F.1 → F.2 → F.3 → F.4),
plus docs.

## Architecture seams (verified)

* **System books** — one source of truth: `SYSTEM_BOOKS`
  (`src/store/mod.rs:29`) + a `SYSTEM_TAG_*` const.
  `ensure_system_books()` auto-creates on open; user/system
  separation is already `system_tag.is_some()` everywhere.
  Notes/Research are the model (free-form prose).
* **AI scope** — the `AiMode` enum (`src/tui/inference.rs:45`):
  `None → Selection → Paragraph → Subchapter → Chapter →
  Book`.  `build_ai_mode_context()` (`app.rs:12558`) is the
  single function turning a scope into context text.
* **Chat pre-seed** — `chat_history: Vec<ChatTurn>`
  (`ChatTurn::User|Assistant`), replayed in
  `spawn_chat_stream` (`src/ai/stream.rs:35`).
* **Multilingual prompts** — the `*_default_prompt(lang_iso)`
  5-language pattern (`app.rs:~19716`) + `resolve_prompt` /
  `active_prompt_language` / `iso_from_long`.  Clone
  show-don't-tell.
* **Free chord** — `Ctrl+B Shift+X` is unbound; joins the
  Shift-family diagnostic cluster (Shift+T sdt, Shift+H
  rhythm, Shift+M rewrite).

## Phase F.1 — The Facts system book

Add `("facts", "Facts")` to `SYSTEM_BOOKS` (after
`research`) + `pub const SYSTEM_TAG_FACTS`.  Update the
doc-comments that enumerate the system-book set.  No
schema, no overlay — it's free-form prose like Notes (see
Decision 2).  `ensure_system_books()` creates it on the
next open; verify it renders in the tree and `inkhaven
doctor` counts it.  Foundation; tiny.

## Phase F.2 — Facts AI scope

`AiMode::Facts`, cycled **after `Book`** (so F9 reads
`… → Chapter → Book → Facts → None`, i.e. Facts sits
between Book and Selection in the wrap).  `next()` /
`label()` / quick-ref text.  A `build_ai_mode_context()`
branch that gathers every Facts-book paragraph
(`system_book_id(SYSTEM_TAG_FACTS)` → `collect_subtree` →
`get_content`) into a context block, formatted like the
Chapter/Book branch but headed `── Facts reference (N) ──`.

## Phase F.3 — Facts-scope chat pre-seed + fact-analysis prompt

When the Facts scope is active, pre-seed the conversation
so the author can interrogate their world's invariants:

* a multilingual **system prompt** —
  `facts_scope_system_prompt(lang_iso)` — that frames the
  model as a facts-analysis / fact-checking assistant
  grounded in the supplied Facts reference, and
* the Facts-book paragraphs loaded as the opening
  `ChatTurn` history so the model already "has" them.

5-language coverage (en/ru/de/fr/es), resolved the same way
as every other prompt.

## Phase F.4 — "Fact check" chord (`Ctrl+B Shift+X`)

`Action::FactCheck` (serde `editor.fact_check`) +
label/description/binding/dispatch; handler
`start_fact_check()` cloning the show-don't-tell flow.  Per
Decision 1, on fire it:

* **auto-locks the AI scope to Paragraph ("local")** — the
  check is about *this* paragraph, never a whole-book send;
* **grounds against the Facts book** — when Facts is
  non-empty, its content is injected as a ground-truth
  reference block ahead of the paragraph, so the model can
  flag contradictions ("the manuscript says snow, but your
  Facts say this region is tropical").  Empty Facts → a
  plain local fact-check.

Adds `fact_check_default_prompt(lang_iso)` (5 languages),
streams the verdict to the AI pane.  KEYBINDING.md row.

## Decisions

1. **The fact-check chord grounds against the Facts book
   and auto-locks scope to local (Paragraph).**  When you
   fact-check a paragraph, the effective scope is forced to
   the local paragraph and the Facts book is injected as
   the authoritative reference — so it checks *this* prose
   against *your* established facts, not the whole
   manuscript against general knowledge.  Falls back to a
   generic local check when the Facts book is empty.
2. **No prose overlay / theme colour for Facts.**  It's
   free-form prose like Notes, not an entity lexicon like
   Characters/Places, so Facts entries don't light up words
   in the manuscript.  (A "fact mention" overlay is an easy
   later add if wanted.)

## Out of scope (later)

* A deterministic (non-AI) contradiction scan of prose
  against structured facts — would need a Facts schema;
  this cycle keeps Facts free-form.
* A `Ctrl+Y`-style Facts lexicon-inference lookup chord.
