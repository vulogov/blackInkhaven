# Inkhaven 1.7.5 — The Engine Begins

_Until now the linguistic layer has measured and described. This release starts
building the other direction: the first pieces of a generative engine that reads
structure rather than counting it — a morphological parser, argument linking, and
an Oracle that judges whether a word could belong to the language. All
deterministic. No new runtime crates._

## A morphological parser

Paradigm generation goes one way: root plus rules produce a form. `parse` goes the
other:

```sh
inkhaven language parse Eldar --word katai
```

It strips the language's known affixes and asks whether what remains is a root in
the dictionary — a genuine reverse of the generator, not a lookup — and returns
every analysis it finds, simplest first. So `katai` comes back as *kata* ‘stone’ +
PL, and a stacked form unwinds to its root through several affixes.

## Argument linking

`link` makes the syntax–semantics interface explicit. Given a verb's valence and
the noun phrases of a clause, it works out each argument's **thematic role**
(agent, patient, theme, recipient), its Role-and-Reference-Grammar **macrorole**
(actor vs undergoer), and its **grammatical relation** (subject, object, indirect
object):

```sh
inkhaven language link Eldar --verb give --args "she, book, him"
```

It reads the valence from the `verb_classes` block, flags when the argument count
doesn't match, and infers a valence from the arguments when the verb is
undeclared.

## The Oracle

`audit` scans the finished lexicon. The **Oracle** judges *arbitrary* input — a
word you are about to coin — and says whether it could be a word of the language,
by linguistic level:

```sh
inkhaven language check Eldar --word katta
```

Level one is phonotactics: segments outside the inventory, and exactly which
declared constraints a word breaks (a geminate, an over-long cluster, a forbidden
sequence). Level two is morphology: does it analyse as root plus affixes, or is it
a listed root? Agreement and syntax join it as the clause engine grows.

## Dependencies & compatibility

**No new runtime crates.** Everything is additive — three new `language`
subcommands (`parse`, `link`, `check`); existing projects and languages are
unchanged. The companion book's command reference is updated to match.
Warning-free (binary and tests). Test suite → 2527.
