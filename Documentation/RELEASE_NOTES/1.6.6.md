# Inkhaven 1.6.6 — Books & Hardening

_A consolidation release: the three companion books brought up to the current
feature scope, and a two-round adversarial hardening pass across the codebase. No
new features, no new runtime crates — the surface you already have, documented in
full and made harder to break._

## The books, brought to current scope

Every companion book was audited against the actual code (feature inventory vs.
coverage) and the gaps filled — in the author's voice, verbatim.

- **Building the World** — a new chapter, **"Drawing the Map with plakat"**, walks
  the whole plakat integration for someone who has never done it: install, the
  MapSpec bridge, `realworld map`, the three styles, DEM round-trips — with **five
  real generated maps** in the book. Plus the `geology.generated` HJSON block (and
  every other block) now has a worked example, twelve new glossary terms, and the
  `co-location` / `coherence` / `places` commands.
- **Constructed Language Development** — the entire **translation subsystem** was
  undocumented; it now has its own chapter, **"Translating with your language"**
  (`translate` / `reverse` / `cross`, the translation memory, `corpus` / `eval`,
  the `.itm` pack), the `doctor` and `define-rule` commands, the eight `lang.*`
  translation Bund words, and the Meta-chapter HJSON schema.
- **The Research Assistant** — the command reference is now complete (`/verify`,
  `/diff`, `/deadsources`, `/sources`, `/forget`, `/rag`, `/chain`, thread flags),
  and a new section documents the **`inkhaven sources` CLI** — BibTeX and
  **CSL-JSON** import/export for a full Zotero round-trip. Its Help-RAG markdown
  mirror was regenerated to match.

## Hardening

Two rounds of adversarial audit (WORLD track + cross-cutting, then conlang +
research/sources + shared plumbing) found and fixed **21 issues** with regression
tests. The full ledger is in
[`Documentation/PROPOSALS/HARDENING_PLAN_1.6.6.md`](../PROPOSALS/HARDENING_PLAN_1.6.6.md).
The load-bearing ones:

- **Reachable panics removed.** Two UTF-8 boundary crashes on realistic input — a
  large non-ASCII `world.hjson` handed to `realworld critique`, and an LLM-emitted
  heading (led by a non-breaking space) in `language grammar-book` / `tutorial`.
- **DoS gaps capped.** An uncapped `geology.generated.plates` (a typo like `7000`)
  could freeze the compile or OOM the process — now clamped, with a warning; the
  DEM decode, `--meter`, `--count`, and the phonology rewrite engine likewise.
- **Silent data-loss fixed.** A Bund script path like `2024-review` mis-resolved to
  a different sibling (a wrong-target delete); BibTeX export left unbalanced braces
  that corrupted the file; three writes (a citation, a provenance row, an imported
  source) reported success while silently failing.
- **Determinism restored.** A climate-zone tie could order two equal-area biomes
  differently across runs — breaking the pure-function-of-(world, seed) contract.
- **Guards added.** Script `ink.tree.delete` / `rename` now refuse a protected
  system book; the research adapters now carry HTTP timeouts (a stalled remote no
  longer hangs the command forever).

## Dependencies & compatibility

**No new runtime crates. No new features, no behavioural changes** — every fix
either removes a crash, closes a resource hole, or corrects a silent failure.
Existing projects are unaffected. Test suite 2313 → 2319.
