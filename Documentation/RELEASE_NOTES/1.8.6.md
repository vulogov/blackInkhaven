# Inkhaven 1.8.6 — Verse Paragraphs (POEM-1, PO-P0)

_The foundation of poetry support: a `para:verse-*` structural paragraph family, so a
poem can live anywhere in a book — an epigraph, a recited stanza, song lyrics — without a
separate project type or hierarchy. This is the first phase of the POEM-1–7 arc; the
metre, rhyme, and Inner Poet layers follow. **No new runtime crates.**_

## The verse paragraph family

Six new structural subtypes, in the same mechanism as `para:code` / `para:math` /
`para:utopia-*`:

| Tag | Glyph |
|---|---|
| `para:verse-line` | `‖` |
| `para:verse-stanza` | `♩` |
| `para:verse-couplet` | `‗` |
| `para:verse-tercet` | `⁚` |
| `para:verse-quatrain` | `⁛` |
| `para:verse-translation` | `⇄` |

They appear under a new **Verse** section in the `i` structural-type picker, carry their
own tree glyph, and are handled by the `Ctrl+B ]` tag inspector like any other `para:*`
tag. A poetry-only project is simply a book whose paragraphs are all verse subtypes; a
prose novel can hold a single recited stanza — nothing about the book structure changes.

## Verse is not prose

Because every verse tag begins `para:`, the existing structural-paragraph gate already
excludes verse from the prose companions (Inner Editor, Inner Socrates, the NARR-1
profiler) and from the prose word count. This release also excludes verse from `inkhaven
style` — its readability metrics and filter-word/repetition detectors skip verse
paragraphs, which have their own analysis coming in the Inner Poet.

## What's next in the arc

POEM-1–7 continues phase by phase: the `poem:` form declaration and forms library, a
natural-language syllabifier, the multilingual rhyme and metre engines (the metre layer
reuses the scansion engine shipped in 1.8.2), the **Inner Poet** companion (`Ctrl+B J →
P`), form-completion and volta awareness, and a poetry-translation workspace. None of it
generates verse — the author writes every word; the tools observe, measure, and report.

## Dependencies & compatibility

**No new runtime crates.** Purely additive — a new `poetry` module, six pickable verse
subtypes, a tree glyph, and a verse-skip in `inkhaven style`; no existing behaviour
changes. Warning-free (binary and tests). Test suite → 2611.
