# 3.0.0 · P1 Stability Audit — Findings Ledger

**Date:** 2026-08-05, on `2.7.0-dev`. **Method:** 7-partition parallel adversarial full-source audit (first full audit since pre-1.9; whole 2.x arc). **Scope:** 304K LOC / 609 modules.

## Headline

The codebase is **fundamentally sound**. Across 304K lines the audit found **zero Critical**, **4 High**, **~8 Medium**, **~5 Low** — and verified the highest-stakes surfaces clean: the **Bund sandbox policy is airtight** (aliases resolve to the denied stub, every registered word is classified, no `STORE_READ` word touches the LLM, fs is project-confined), **UTF-8/byte-boundary discipline is airtight** (multilingual prose can't panic-slice), the **panic surface is almost entirely clean** (the ~2,092 `unwrap`s are overwhelmingly test-only or provably guarded), **untrusted-input parsers are proptested + capped**, and **manuscript saves are atomic and write the focused doc**. The `calc.factorial` DoS from the pre-1.9 audit is confirmed fixed.

The findings cluster into **four themes**, each with a fix pattern already used elsewhere in the tree. None is a coherence crisis; this is a modest, well-characterized punch-list.

## Themes

1. **Cost-rail bypass (systemic).** ~half the advisory LLM "slow tracks" call `collect_blocking` directly instead of the gated `slow_llm_call` rail, so they're invisible to `inkhaven cost` and skip the soft-cap/daily-cap preflight. Gated: inner_editor, inner_socrates, ken/deep, lector, continuity-coherence, world-fact-check. **Bypassing: utopia, redline, inner_poet, inner_theologian, inner_stylist, myth, character.** Against the "cost informs, never surprises" principle.
2. **Atomicity gaps.** A handful of writes skipped the `io_atomic`/`engine.transaction` bar: chronicle milestone insert (High — non-rebuildable), epub export, wordnet index, research report exports.
3. **Schema versioning (freeze-specific).** 14 per-feature DuckDB stores lack the `_inkhaven_schema` anchor — the one class of finding you cannot fix after the freeze.
4. **Per-frame hot-path cost.** Two TUI draw paths recompute each frame instead of using the established `content_hash` cache (Output-pane DB query; style-warning pass).
